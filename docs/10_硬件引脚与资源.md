### 2.3 音频：板载 MAX98357A（I2S DAC + Class-D 功放）

| 信号 | FPGA 引脚 | MAX98357A 引脚 | 说明 |
|---|---|---|---|
| I2S_BCLK | PIN56 | BCLK (C1) | 位时钟 |
| I2S_LRCK | PIN55 | LRCLK (C3) | 左右声道时钟 |
| I2S_DIN | PIN54 | DIN (B1) | 串行数据 |
| PA_EN | **PIN51** | SD_MODE (A1) | 高 = 使能 + 左声道；低 = 关断 |
| AUDIO_OUTP/N | J4（2 脚排针） | OUTP/OUTN | 接 4Ω / 8Ω 小喇叭 |

- 板载芯片是 **MAX98357A**，只支持 **I2S**（MAX98357B 才是 left-justified）。
- **不需要 MCLK**，只需要 BCLK / LRCLK / DIN。
- 48kHz 时 BCLK = 1.536MHz（32×）或 3.072MHz（64×）。
- `GAIN_SLOT` 增益：GND 经 100k = 15dB；GND = 12dB；悬空 = 9dB；VDD = 6dB；VDD 经 100k = 3dB。
- 有源蜂鸣器不能替代喇叭；它只能发固定音高"嘀"。
- 外接 I2S DAC 模块不再是必需品，仅作备份。

### 2.4 时钟与 MS5351

| 信号 | FPGA 引脚 | 说明 |
|---|---|---|
| SYS_CLK | PIN4 | 27MHz 晶振 |
| 5351CKP / 5351CKN | PIN10 / PIN11 | MS5351 差分时钟输出 → SYS_GCLK6_P/N |
| 5351clk2 | PIN13 | MS5351 单端时钟 → SYS_LPLL2_in |
| 5351_IIC_SCL / SDA | 待核实 ❓ | 需查原理图或 wiki 的 MS5351 配置页 |

- 主方案：27MHz → rPLL → 100.8MHz → 分频 2100 → 48kHz 采样使能。
- 备选：用 MS5351 生成 12.288MHz / 24.576MHz 音频时钟；需要 FPGA 通过 I2C 配置 MS5351（P3 再评估）。

### 2.5 USB / JTAG

| 信号 | FPGA 引脚 | 说明 |
|---|---|---|
| JTAG_TMS | PIN5 | BL616 USB-JTAG |
| JTAG_TCK | PIN6 | |
| JTAG_TDI | PIN7 | |
| JTAG_TDO | PIN8 | |
| UART TX / RX | PIN69 / PIN70 | BL616 USB-UART |

> ⚠️ **Tang Nano 20K 有两个 USB-JTAG / UART 硬件版本**：
> - **FTDI FT2232 版**：Windows 显示 `USB Serial Converter A/B`（FTDI）；Gowin Programmer 选 `USB Debugger A` / `FT2CH`；需要 **FTDI D2XX 驱动**。
> - **BL616 版（v3923 原理图）**：Windows 显示 `Gowin USB Cable` / `USB Serial Device`；Gowin Programmer 选 `Gowin USB Cable`；需要 **BL616 驱动**。
>
> **本队当前板子实测**：设备管理器显示 FTDI `USB Serial Converter A/B`，Programmer 只列出 `USB Debugger A`，因此按 **FT2232 路径**处理。
> PCB 丝印为 v3923，与 v3923 原理图的 BL616 不一致，需进一步确认 USB 芯片；FPGA 引脚与资源不受影响。

## 四、工具链

- **Gowin EDA V1.9.11.03 Education**：支持 `GW2AR-LV18QN88C8/I7`，**无需 license**，仅供教育 / 研究 / 非商业用途。
- Windows 11 安装前关闭 **Smart App Control**，否则可能被拦截。
- 内存：GW2AR-18 最低 1GB，推荐 1.5GB。
- 安装目录内含手册：SUG501（快速安装启动）、SUG918（快速入门）、SUG100（用户指南）、SUG502（Programmer）、UG286（Clock）、UG285（BSRAM/SSRAM）、UG287（DSP）。
- 板子体检：先烧预编译 `blink_led.fs`（SRAM Program），再自己综合一遍。
- ⚠️ **烧录电缆按板子版本选择**：FT2232 版选 `USB Debugger A` / `FT2CH`，装 FTDI D2XX 驱动；BL616 版选 `Gowin USB Cable`，装 BL616 驱动。当前板子按 FT2232 处理。
