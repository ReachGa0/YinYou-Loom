### 2.3 音频：板载 MAX98357A（I2S DAC + Class-D 功放）

| 信号 | FPGA 引脚 | MAX98357A 引脚 | 说明 |
|---|---|---|---|
| I2S_BCLK | PIN56 | BCLK (C1) | 位时钟 |
| I2S_LRCK | PIN55 | LRCLK (C3) | 左右声道时钟 |
| I2S_DIN | PIN54 | DIN (B1) | 串行数据 |
| PA_EN | **PIN51** | SD_MODE (A1) | 高 = 使能 + 左声道；低 = 关断 |
| AUDIO_OUTP/N | J4（2 脚排针） | OUTP/OUTN | 接 4Ω / 8Ω 小喇叭 |

- 板载芯片是 **MAX98357A**，只支持 **I2S**（MAX98357B 才是 left-justified）。
- **不需要 MCLK**，只需要 BCLK / LRCLK / DIN。
- 本设计采用 48 BCLK / LRCLK 周期、左右各 24bit 的格式，48kHz 时 BCLK = 2.304MHz。
- MAX98357A 也支持 32× / 64× 位时钟；以当前 I2S 发送器的 48 拍帧格式为准。
- `GAIN_SLOT` 增益：GND 经 100k = 15dB；GND = 12dB；悬空 = 9dB；VDD = 6dB；VDD 经 100k = 3dB。
- 有源蜂鸣器不能替代喇叭；它只能发固定音高"嘀"。
- 外接 I2S DAC 模块不再是必需品，仅作备份。

### 2.4 时钟与 MS5351

| 信号 | FPGA 引脚 | 说明 |
|---|---|---|
| SYS_CLK | PIN4 | 27MHz 晶振 |
| 5351CKP / 5351CKN | PIN10 / PIN11 | MS5351 差分时钟输出 → SYS_GCLK6_P/N |
| 5351clk2 | PIN13 | MS5351 单端时钟 → SYS_LPLL2_in |
| 5351_IIC_SCL / SDA | 待核实 ❓ | 需查原理图或 wiki 的 MS5351 配置页 |

- 主方案：27MHz → rPLL(3/8/8) → 72MHz → `frac_div(8/125)` → 4.608MHz 位节拍 → 长期平均 48kHz。
- 备选：用 MS5351 生成 12.288MHz / 24.576MHz 音频时钟；需要 FPGA 通过 I2C 配置 MS5351（P3 再评估）。

### 2.5 USB / JTAG

| 信号 | FPGA 引脚 | 说明 |
|---|---|---|
| JTAG_TMS | PIN5 | BL616 USB-JTAG |
| JTAG_TCK | PIN6 | |
| JTAG_TDI | PIN7 | |
| JTAG_TDO | PIN8 | |
| UART TX / RX | PIN69 / PIN70 | BL616 USB-UART |

> ⚠️ **Tang Nano 20K 有两个 USB-JTAG / UART 硬件版本**：
> - **FTDI FT2232 版**：Windows 显示 `USB Serial Converter A/B`（FTDI）；Gowin Programmer 选 `USB Debugger A` / `FT2CH`；需要 **FTDI D2XX 驱动**。
> - **BL616 版（v3923 原理图）**：Windows 显示 `Gowin USB Cable` / `USB Serial Device`；Gowin Programmer 选 `Gowin USB Cable`；需要 **BL616 驱动**。
>
> **本队当前板子实测**：设备管理器显示 FTDI `USB Serial Converter A/B`，Programmer 只列出 `USB Debugger A`，因此按 **FT2232 路径**处理。
> PCB 丝印为 v3923，与 v3923 原理图的 BL616 不一致，需进一步确认 USB 芯片；FPGA 引脚与资源不受影响。

## 六、P5 交互接口预算（v0.5，实物排针可用集）

> 目标：先确认引脚和器件数量，暂不写 `.cst`。
>
> 重要更正：Tang Nano 20K 的排针**没有引出 PIN32-PIN38**。
> 旧版 P5 预算中的 `PIN32-PIN38` 不可用于母板接口，已从本版删除。
> 当前方案只使用数据手册第 5 页明确引出的 34 个 IO。

### 6.0 两条核心板排针的物理顺序

推荐的统一方向是两条 1x20 母座的 `1` 脚都位于 Tang Nano 20K 的
USB-C 一端。当前母板原理图的 `J_CORE_B` 尚未统一，而是反向放置，因此
其原理图脚号与物理位置的换算必须单独记录。

| 排针 | 从 USB 端到 HDMI 端的 20 个物理位置 |
|---|---|
| `J_CORE_A` | `73,74,75,85,77,15,16,27,28,25,26,29,30,31,17,20,19,18,3V3,GND` |
| `J_CORE_B` | `5V,GND,76,80,42,41,56,54,51,48,55,49,86,79,GND,3V3,72,71,53,52` |

当前母板采用 `J_CORE_B` 反向放置，因此其原理图引脚编号与物理位置对应为：

```text
J_CORE_B-20 = J_CORE_B 物理位置 1 = 5V
J_CORE_B-19 = J_CORE_B 物理位置 2 = GND
J_CORE_B-6  = J_CORE_B 物理位置 15 = GND
J_CORE_B-5  = J_CORE_B 物理位置 16 = 3V3
```

五引脚 EC11 兼容编码器接线建议：

```text
A 相  -> PIN25
B 相  -> PIN27
公共端 C -> GND
VCC -> +3V3
GND -> GND
```

A/B 建议启用 FPGA 内部上拉。当前模块没有单独引出按压开关，
Major / Minor 使用 PIN31 上的 `KEY_SCALE` 外接按键或板载 S2。
四个功能按键均采用 FPGA 内部上拉和 RTL 软件消抖，不增加硬件消抖电路。

引脚合计：

```text
排针可用 IO：34
音频占用：4
交互与显示占用：24
状态灯或板载 WS2812 保留：6
总计：34 个排针 IO 已全部规划
```

### 6.3 触摸圆环方案（后续增量）

两圈共 24 个电容触摸扇区，直接占用 24 个 FPGA IO 会让排线和布局过于复杂。
如果 v1.0 完成后仍有余力开发触摸，建议使用 **3 片 CD74HC4067 16 通道模拟多路复用器**：

| 模块 | 用途 |
|---|---|
| 内圈模块 | 内圈 12 个扇区 + 预留 4 通道 |
| 外圈模块 | 外圈 12 个扇区 + 预留 4 通道 |
| 第三圈预留模块 | 未来最外圈触摸 12 通道 |

三片共用的 4 根地址线由 PIN41 / PIN42 / PIN48 / PIN49 控制。
当前使用 PIN52 / PIN53 读取两圈触摸，PIN86 预留给第三圈。

当前成品模块的丝印制包含 `C0-C15 / S0-S3 / EN / SIG / VCC / GND`。
这些名称描述模块功能，**不等于芯片 DIP 封装的 pin1-pin24**，也不应假定
模块排针一定按上述顺序连续排列。`SIG` 是公共模拟端（芯片资料中也写作
`I/O`），三片必须分别接到 PIN52 / PIN53 / PIN86，不能并联；`VCC` 接
`+3V3`，`EN` 为低有效并接 `GND`。

正式原理图必须等实物到货后填写“模块丝印 -> 实物排针脚号”表。若实物丝印
确实写成 `S10` 而不是 `SIG`，先查模块资料并用万用表确认其与模拟开关公共
端的连通关系，不能仅凭名称猜测。

这样引脚预算可控，但也引入了一个必须在触摸增量阶段先验证的风险：

- CD74HC4067 的导通电阻和寄生电容会改变 RC 测时结果。
- 必须先做一个 4 通道小实验，确认触摸值可稳定区分，再扩展到 24 通道。
- 若多路复用方案不稳定，回退到直接 GPIO 扫描；引脚数会增加，但不需要改音频核心。

### 6.4 I2C 地址规划

| 总线 | 设备 | 地址 |
|---|---|---|
| I2C | ADS1115 #1：4 个效果旋钮 | 0x48 |
