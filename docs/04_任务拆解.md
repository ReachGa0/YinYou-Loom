# 吟游 Loom · 任务拆解（阶段版）

> **吟游 Loom** —— 基于 Sipeed Tang Nano 20K 的纯硬件实时多音色合成电子乐器引擎
> 芯片：**GW2AR-LV18QN88C8/I7**（20736 LUT4 / 15552 FF / 2 PLL / 多个 DSP（18×18 乘法）/ BSRAM 容量待核实）
> 参赛：2026 全国大学生嵌入式芯片与系统设计竞赛 · FPGA 创新设计赛道 · 高云半导体 · 选题二
>
> 确认决策：复音 **4（可扩展 8）** ｜ 交互 **部分自研** ｜ 架构 **三层**
>
> 本文件是**阶段与任务的拆解**，不含时间排期。每个任务都应能对应到仓库里的目录或文件。

## 1.2 `.gitignore` 要点

必须排除（否则仓库会被综合产物撑爆）：

```gitignore
# 高云综合产物
fpga/build/
*.fs
*.bin
*.rbf
*.prj
*.ipc
*.log
*.html

# 仿真产物
*.vvp
*.vcd
sim/*.wav
sim/*.txt
*.out

# Python
__pycache__/
*.pyc

# 编辑器
.vscode/
.idea/
```

> ⚠️ **`data/wavetables/*.hex` 要提交**（是可复现的生成物，且 RTL 依赖它），
> 但**仿真输出 wav 不要提交**。

## 1.3 分支与提交约定（建议）

| 分支 | 用途 |
|---|---|
| `main` | 始终可综合、可交付 |
| `feat/xxx` | 单个功能开发 |

**提交信息**带上阶段号，便于回溯：
```
[P2] 实现 voice_osc 相位累加器与查表
[P3] 修正 i2s_tx 的 LRCLK 相位
[P5] 调整测试音为相干采样频率
```

| P6.4 | **频谱实测：数出独立谱峰** | — |

**产出物**：可一键进入的测试模式 + 完整的验证方案文档

**验收标准**
- [ ] 一键进入测试态，输出 N 路固定频率
- [ ] **频谱仪上能数出 N 个独立谱峰**，数量 = 振荡器数
- [ ] 测得端到端延迟 ≤10 ms，**测量方法已文档化**
- [ ] 能现场翻 RTL 逐模块讲清音频通路，证明无预录

**两个必须避开的坑**

| 坑 | 后果 | 正确做法 |
|---|---|---|
| 测试音选成谐波关系（440/880/1320） | 谱峰重叠，证明不了"独立" | 选非谐波关系（如 A4/C5/E5/G5 = 440/523/659/784） |
| 未用相干采样 | 谱峰散开成一堆小峰，像噪声 | 各频率取 `fs/N` 的整数倍（11.72 Hz 倍数） |

> ⚠️ **P6.5 的测量边界必须写清楚**：从传感器变化算起？含不含 DAC 重建延迟？
> 评委一定会追问这一点。

**阶段门**：P6.4 完成 —— 吞吐量指标可被现场验证。

**砍掉顺序（时间不够时从下往上砍）**

1. P4S.6 混响（最先砍）
2. P4S.8 视觉 → 降级为板载 LED
3. P4S.5 延迟 → 只保合唱
4. P4S.1 32 复音 → 回落到 16，保留可扩展论证
5. P4S.7 音色 3–4 → 回落到 2 种
6. **绝不砍**：基础要求 + P4S.3 测试模式 + P4S.9 延迟实测 + P4S.10 FPGA 考核备考 + P4S.11 报告 / 视频

**新手提示**

- 先做 P1 / P2（不依赖板子），把「仿真能出声」跑通，再想 32 复音。
- 32 复音不是「多写 24 份代码」，而是把 `VOICES` 从 8 改成 32，然后看综合报告和时序。
- 效果器先从**合唱**开始，它只需要一条很短的延迟线；混响是最后才碰的。
- FPGA 基础考核要和项目同步准备，不要等到决赛前一周。

**验收标准（冲刺项，非必达）**

- [ ] `VOICES=32` 综合通过，资源报告记录 LUT / FF / BSRAM / DSP
- [ ] 测试模式频谱上可数出 32 个独立谱峰
- [ ] 合唱 / 延迟至少一个可开关，且不引入爆音
- [ ] 延迟实测 ≤5ms（含 / 不含 DAC 写清楚）
- [ ] 至少一项视觉反馈（LED / OLED）在演奏时实时变化
- [ ] FPGA 基础编程考核模拟题通过
