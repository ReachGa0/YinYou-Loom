## 1. 产品定位与使用场景

`[已确认]`

吟游 Loom 是一台桌面式 FPGA 电子乐器。v1.0 使用外接按键 / 编码器完成选音与模式切换，使用双轴摇杆和超声波模块完成连续演奏控制；后续产品形态可把两圈触摸环作为主要演奏区。2.4 寸 TFT、LED 和外圈状态灯用于显示当前演奏状态，帮助现场演示与评委验证。

| 项目 | 定义 |
|---|---|
| 产品形式 | 桌面乐器，放在桌面上演奏 |
| 主要用户 | 演奏者、比赛评委、现场观众 |
| 核心卖点 | 纯 FPGA 实时合成、多维交互、五度圈和声、现场可验证 |
| 演示场景 | 单人演奏、和弦演奏、效果器演示、频谱测试模式 |
| 非目标 | 不做蓝牙、不做手机 App、不做复杂音序器 |

一句话定位：

> 一台能直接演奏、能做和声表达、能现场证明没有播放录音的纯硬件合成器。

## 2. 外观与物理布局

`[已确认结构，尺寸待定]`

建议先做一个约 `240 mm × 160 mm` 的桌面面板。Tang Nano 20K 放在面板后方或右侧，同心圆演奏区放在右侧，功能键、摇杆、效果旋钮和显示区域集中在左侧。

三个视觉圆环从外到内分别是：

```text
最外圈：LED 状态环，只显示，不触摸
中间圈：触摸外环，演奏高八度音符或大三和弦
最内圈：触摸内环，演奏低八度音符或小三和弦
```

```text
┌──────────────────────────────────────────────────────┐
│  左功能区                                 右演奏区   │
│  ┌───────────────────────┐          ╭───────────╮   │
│  │ 2.4 寸 SPI TFT        │        ╭─┤ 外圈 LED ├─╮ │
│  │ 上半区：全局状态      │       ╭┤ │ 触控外环 │ ├┤ │
│  │ 下半区：4 个效果参数  │       ││ │ 触控内环 │ ││ │
│  └───────────────────────┘       ╰┤ ╰───────────╯ ├╯ │
│  ┌────┬────┬────┬────┐              ╰─────────────╯ │
│  │SCALE│PLAY│音色│ FX │                            │
│  └────┴────┴────┴────┘                              │
│  ○ 摇杆        K1  K2  K3  K4                       │
│                                 喇叭输出口  超声波  │
└──────────────────────────────────────────────────────┘
```

布局原则：

- 三个圆环在视觉上同心，最外圈只承担 LED 状态显示。
- 触控外环和触控内环之间保留足够间隙，避免串扰。
- 左侧集中功能键、摇杆、2.4 寸 TFT 和四个效果旋钮，右侧只保留演奏圆环。
- TFT 上半区显示全局状态，下半区与四个效果旋钮对齐显示参数。
- 双轴摇杆放在左手容易操作的位置，演奏时右手负责圆环，左手负责摇杆与功能键。
- FPGA 下载口和电源口留在侧面或后方。

## 3. 同心圆演奏区

`[后续增量]`

两圈触摸都按 12 个扇区设计，扇区角度对应五度圈上的 12 个根音：

```text
C -> G -> D -> A -> E -> B -> F# -> C# -> G# -> D# -> A# -> F -> C
```

两圈触摸的职责由 `PLAY MODE` 决定。

### 独奏模式

| 圆环 | 行为 |
|---|---|
| 触摸外环 | 当前根音的高八度音符 |
| 触摸内环 | 当前根音的低八度音符 |
| 最外圈 LED | 高亮当前调性内的音，调外音仍可演奏但颜色不同 |

独奏模式下，两圈组成两个八度的单音演奏区。触摸哪个扇区，就演奏该扇区对应的音名。

### 和弦模式

| 圆环 | 行为 |
|---|---|
| 触摸外环 | 对应根音的大三和弦 |
| 触摸内环 | 对应根音的小三和弦 |
| 最外圈 LED | 高亮当前调性内的自然和弦根音 |

例如当前根音是 C：

```text
触摸外环 C 扇区 -> C 大三和弦（C + E + G）
触摸内环 C 扇区 -> C 小三和弦（C + Eb + G）
```

和弦模式一次触摸分配一个三声部和弦组，三个声部使用同一个包络触发和释放。

### 模式切换规则

```text
按下 PLAY MODE
    -> 当前所有声部进入 Release
    -> 清空触摸键锁存状态
    -> 切换独奏 / 和弦映射表
    -> TFT 和最外圈 LED 更新状态
```

`[必须]` 板载 S1、S2 必须保留为保底输入。即使超声波或后续触摸不可用，
选音和模式切换仍由按键 / 编码器完成。

## 4. 功能控件

`[已确认]`

核心功能控件如下：

| 控件 | 操作 | 结果 |
|---|---|---|
| `KEY` 旋转编码器 | 顺时针 / 逆时针旋转 | 在 12 个调性之间循环 |
| `SCALE` 按钮 | 短按 | 切换 Major / Minor |
| `PLAY MODE` 按钮 | 短按 | 独奏模式 / 和弦模式切换 |
| `TIMBRE` 按钮 | 短按 | 切换 2 种音色 |
| `FX` 按钮 | 短按 | 循环选择效果器 |
| 双轴摇杆 | 左 / 右 | Pitch Bend，微量降低 / 升高音高，可手动产生颤音 |
| 双轴摇杆 | 前 / 后 | 和弦扫弦间隔 / 琶音速度；和弦触发时锁存 |
| 超声波模块 | 手距前后移动 | 靠近力度大 / 动态强，远离力度小 / 动态弱 |
| 效果参数旋钮 K1-K4 | 旋转 | 调节当前效果器的 4 个参数 |

四个外接功能按键使用机械轻触开关，采用 FPGA 内部上拉和 RTL 软件消抖。
第一版不增加 RC、施密特触发器或专用硬件消抖芯片。

行为必须同时定义声音和视觉反馈，例如：

```text
按下 TIMBRE
    -> 音色从 Warm Sine 切到 Bright Square
    -> TFT 全局状态区立即更新
    -> WS2812 闪一次作为确认
```

板载键保底映射：

| 板载按键 | 保底功能 |
|---|---|
| S1 | 切换音色 |
| S2 | 保底切换 Major / Minor 或进入测试模式 |

## 5. KEY 旋转编码器与 SCALE 按键

`[已确认]`

使用 12 档 EC11 旋转编码器。当前实物模块的丝印包含
`A / C / B / VCC / GND`，没有单独引出按压开关；物理排列和 1 脚方向以实物为准。
调性顺序与五度圈一致：

```text
C -> G -> D -> A -> E -> B -> F# -> C# -> G# -> D# -> A# -> F -> C
```

交互定义：

| 操作 | 结果 |
|---|---|
| 顺时针旋转 | 移向下一个五度调性 |
| 逆时针旋转 | 移向上一个五度调性 |
| 按下 `SCALE` 按钮 | 在当前根音上切换 Major / Minor |

TFT 全局状态区显示：

```text
Key: C Major
Mode: CHORD
Timbre: Warm Sine
Effect: CHORUS
Voices: 3/4
```

第一版只实现 `Major / Minor`。Dorian、Mixolydian 等调式放到后续版本。
如果以后更换为带独立 `SW` 的编码器，可以把开关接到同一个
`KEY_SCALE` 输入端，不需要改变功能层接口。

## 6. 效果器控制区

`[已确认结构，效果器数量待定]`

效果器参数使用 4 个 10 kΩ 线性电位器，接入 ADS1115，再通过 I2C 输入 FPGA。

```text
K1 K2 K3 K4
  |  |  |  |
  +--+--+--+-- ADS1115 -- I2C -- FPGA
             |
        2.4 寸 SPI TFT
```

| 效果器 | K1 | K2 | K3 | K4 |
|---|---|---|---|---|
| Chorus | Depth | Rate | Mix | Tone |
| Delay | Time | Feedback | Mix | Tone |
| Space | Size | Damping | Mix | Pre-delay |

第一版优先实现合唱。合唱使用较短的调制延迟线，BSRAM 和算法复杂度低于长延时与混响；若实际时序或资源评估不合适，再退到简单延时。第一版不提前承诺同时启用多个效果器。

TFT 下半区与四个旋钮对齐。切换效果器时，四列的标签和值整体更新，但物理旋钮不移动。

第一版采用绝对映射：

```text
切换到新效果器
    -> 读取四个旋钮当前位置
    -> 作为新效果器的参数初值
    -> 屏幕显示新参数
```

如果以后发现切换时声音跳变明显，再加入 soft-takeover 或参数平滑。

## 7. 演奏维度

`[已确认 v1.0]`

| 维度 | 第一版来源 | 映射 | 要求级别 |
|---|---|---|---|
| 选音 | 按键 / 后续两圈触摸扇区 | 选择音符或和弦根音 | 必须 |
| 调性与调式 | KEY 旋转编码器 + SCALE 按键 | 改变音阶映射与 LED 高亮 | 必须 |
| Pitch Bend | 摇杆左 / 右 | 实时微量音高偏移，建议 ±2 半音 | 必须 |
| 力度 / 动态 | 超声波手距 | note-on 锁存 velocity；持续时慢速 expression | 必须 |
| 扫弦间隔 | 摇杆前 / 后 | 和弦触发时锁存，决定扫弦 / 琶音错开时间 | 目标，v1.0 纳入 |
| 拨弦 | 短按 / 快速释放识别 | 快速衰减的拨弦包络 | 必须 |

如果超声波调试延期，保底可以先用固定力度保证 Pitch Bend 与扫弦间隔两维成立，
但最终报告如果要写三维，必须补上真实力度来源。v1.0 完整输入语义和评分映射见
`docs/16_V1范围与输入语义.md`。

触发与拨弦示例判定：

- 按下持续超过 `120 ms`，识别为普通触发。
- 按下后快速释放，识别为拨弦。
- 具体阈值应通过实机演奏调整。

摇杆前后只控制一个“扫弦时间”参数，不把前、后算作两个维度。向后拉接近同时
触发，中心小幅扫弦，向前推逐步变成琶音。该值只在和弦触发时采样，避免按住
和弦时连续变化造成声部抢占或节奏抖动。

## 8. 音色与合成行为

`[已确认基础范围]`

第一版提供 2 种音色：

| 音色 | 声音感觉 | 用途 |
|---|---|---|
| Warm Sine | 柔和、纯净、适合展示基频 | 基础演示与频谱测试 |
| Bright Square | 明亮、有明显谐波 | 演示音色切换差异 |

旧 OLED 联合 demo 已实机验证两种音色和合唱开关。方波不采用满幅波表：
相同峰值下，方波的奇次谐波集中在小喇叭较敏感、较高效的频段，实听会明显
大于正弦。当前 `make_square` 使用满幅 `1/4`，即 `0x2000 / 0xE000`，听感已经
回到合理的音色差异范围，同时保留“明亮、有明显谐波”的特征。最终总音量由
整机音量旋钮统一控制，不再通过提高正弦波来补偿，因为正弦波表已经接近满幅。

| 参数 | 第一版目标 |
|---|---|
| 基础复音 | 4 |
| 可扩展复音 | 8 |
| 音色数量 | 2，实时切换 |
| 和弦支持 | 一次至少可演奏一个三和弦 |
| 包络 | ADSR，所有声部独立 |
| 测试模式 | 输出多路非谐波固定频率 |

和弦模式下一次触摸占用 3 个声部。基础 4 复音时，可以演奏一个三和弦并额外保留一个声部；如果要演奏七和弦、两个同时进行的和弦或和弦加低音，建议把目标提升到 8 复音。

复音数会影响：

- 同时能响多少个音或和弦。
- 一个三和弦占用 3 个声部，四声部和弦占用 4 个声部。
- Release 尾音也会占用声部，快速换和弦时 4 复音更容易发生声部抢占。
- 测试模式下可同时输出并计数的独立振荡器数量。
- LUT、FF、DSP 和混音器规模，但波表共享，BSRAM 不会随声部数线性增长。

建议把基础目标保持在 4 复音，把产品演示目标设为 8 复音。8 复音可以让一个三和弦自然释放，同时演奏下一个和弦，更适合和弦模式。

## 9. 工作模式与状态机

`[已确认结构]`

```text
BOOT -> PERFORM <-> CONFIG
              \        /
               TEST

任何状态异常 -> FAULT -> 等待复位
```

| 模式 | 进入方式 | 功能 |
|---|---|---|
| BOOT | 上电或复位 | 等待 PLL 锁定，初始化显示 |
| PERFORM | 默认模式 | 独奏 / 和弦演奏、切音色、选调 |
| CONFIG | 组合键或保留入口 | 设置力度、表情范围和灯效开关 |
| TEST | 长按 PLAY MODE 2 秒 | 输出多路固定测试频率 |
| FAULT | 检测到异常 | 静音并显示错误状态 |

`[必须]` 测试模式必须能一键进入，并且不能被普通演奏输入干扰。

## 11. 输入冲突与优先级

`[已确认原则]`

优先级从高到低：

```text
FAULT > TEST > CONFIG > PERFORM
```

规则：

- TEST 模式下忽略触摸环和超声波输入，只保留退出测试模式的操作。
- CONFIG 模式下演奏区可以静音，避免调整参数时误发声。
- 切换 `PLAY MODE` 时先释放所有声部，避免和弦组在切换中卡住。
- 旋转 `KEY` 编码器时不触发声音，只更新调性和显示。
- 按下 `SCALE` 按键时只切换 Major / Minor，不改变当前调性。
- 同一个音符被重新触发时，优先复用原声部，避免重复占用。
- 声部不足时，优先替换最早释放或最早触发的声部。
- 超声波更新较慢，不能同时用于高频音高控制；建议只控制连续表情。

## 12. 启动与异常行为

`[已确认原则]`

上电流程：

1. FPGA 配置完成。
2. PLL 锁定。
3. TFT 显示启动画面。
4. 初始化按键、编码器、触摸、超声波和 ADS1115。
5. 最外圈 LED 和 WS2812 自检。
6. 进入 PERFORM，默认静音，等待第一次演奏。

异常策略：

| 异常 | 行为 |
|---|---|
| PLL 未锁定 | 关闭 PA，保持静音 |
| 触摸未接入 | 自动回退到板载按键 |
| KEY 编码器异常 | 保持上一次调性，TFT 显示错误状态 |
| 摇杆异常 | 音高回中，力度使用固定值 |
| ADS1115 异常 | 效果参数保持默认值，音频继续运行 |
| 超声波异常 | 表情量冻结，不阻塞发声 |
| TFT 异常 | 不影响音频和演奏 |
| 喇叭未接 | 逻辑继续运行，无法自动检测 |

## 14. 验收与演示流程

`[示例]`

建议演示流程：

1. 上电，展示 TFT 启动、外圈 LED 和 WS2812 自检。
2. 旋转 KEY 编码器，演示调性切换，外圈 LED 跟随变化。
3. 按下 SCALE 按键，切换 Major / Minor。
4. 在独奏模式下触摸两圈，演示高低八度演奏。
5. 左右拨动摇杆，演示 Pitch Bend 和手动颤音。
6. 前后推动摇杆，和弦模式下演示扫弦与琶音间隔。
7. 切换 PLAY MODE，进入和弦模式。
8. 触摸外圈和内圈，演示大三和弦和小三和弦。
9. 手在超声波前方前后移动，演示力度 / 动态变化。
10. 切换音色和效果器，旋转参数旋钮，展示参数屏动态变化。
11. 长按 PLAY MODE 进入测试模式。
12. 用频谱仪展示多路固定频率和独立谱峰。
12. 恢复演奏模式，完成现场演奏。

- 效果器参数屏与旋钮映射录像。
- 测试模式频谱照片。
- 实际延迟测量结果与测量边界。
- FPGA 资源占用报告。

## 15. 与系统接口的关系

`[建议保留]`

产品层不应直接修改振荡器或混音器内部，而是通过状态接口读取信息。建议交互层向和声映射与显示层提供：

```verilog
key_root[3:0]
key_mode[1:0]
play_mode
ring_touch_mask[1:0][11:0]
joystick_x
joystick_y
expression
current_timbre
effect_select
effect_param[3:0]
system_mode
```

显示层只读取这些状态，不反向修改音频参数。这样 TFT、LED、WS2812 和后续外圈触摸都可以增量扩展，不会导致合成核心返工。

系统分层：

```text
KEY 编码器 / SCALE 按键 / 摇杆 / 超声波模块 / 功能键
                    |
                 input_map
                    |
               harmony_map
                    |
          note_on / note_off / chord_group
                    |
              voice_alloc
                    |
              synthesis / effects
                    |
                   mixer
                    |
                  i2s_tx
```

效果器和显示使用独立控制通路：

```text
效果参数旋钮 -> ADS1115 -> effect_ctrl -> 效果器参数
系统状态 ------------------> display_ctrl -> TFT / LED / WS2812
```
