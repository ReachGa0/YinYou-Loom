# P5 网络映射表

> 状态：v1.3，模块接线与原理图网络基线；**PCB 暂缓**
> 日期：2026-09-22
> 说明：FPGA 侧引脚已经锁定；模块侧只锁定“丝印信号 -> 母板网络”，
> 实物排针脚号和 1 脚方向必须逐件测量后填写。
> 芯片级参考：TI `CD74HC4067`、TI `ADS1115` 数据手册；核心板以
> Sipeed Tang Nano 20K Datasheet V1.3 为准；模块脚号以实物丝印和测量为准。

当前阶段先用本表做面包板和杜邦线接线，并把模块丝印映射到 FPGA 网络；
PCB 焊盘布局暂不推进。恢复 PCB 时，仍需逐件补齐本表的实物排针脚号和
1 脚方向，不能直接按网络名自动摆放连接器。

## 1. 使用规则

- `J_CORE_A` 的 1 脚在 Tang Nano 20K 的 USB-C 一端。
- `J_CORE_B` 当前反向放置，因此其原理图 20 脚在 USB-C 一端。
- 电源和地使用网络端口：
  - `+3V3`
  - `+5V`
  - `GND`
- 普通信号使用网络标签，例如 `TFT_SCLK`、`I2C_SDA`。
- 两个同名网络标签在整张原理图中电气相连。

### 1.1 三层引脚不能混用

本项目同时存在三类“引脚号”，文档和原理图必须明确区分：

1. **FPGA 引脚号**：例如 `PIN52`，来自 Tang Nano 20K 约束和核心板接口。
2. **芯片封装引脚号**：例如 CD74HC4067 的 DIP pin1-pin24，只用于裸芯片设计。
3. **成品模块排针脚号**：由模块 PCB 丝印和实际排针位置决定，可能与芯片封装完全不同。

本表只把第 1 类和第 3 类通过“模块丝印信号名”关联起来。除已经逐脚核实的
`J_CORE_A` / `J_CORE_B` 外，不根据常见模块图片、卖家页面或芯片封装顺序
推断成品模块的排针号。

实物到货后按下表记录，未填写的模块不得按推测顺序转为 PCB：

| 实例位号 | 模块丝印/功能 | 1 脚或缺口方向 | 实物排针脚号 | 母板网络 | 是否已用万用表确认 |
|---|---|---|---|---|---|
| 例：`J_ADC_KNOB` | `A0` | 按实物填写 | 待填 | `ADC1_A0` | [ ] |

## 4. 各模块网络分配

### 4.1 2.4 寸 SPI TFT

| 模块信号 | FPGA 引脚 | 网络名 | 方向 |
|---|---:|---|---|
| SCLK | 71 | `TFT_SCLK` | FPGA 输出 |
| MOSI | 72 | `TFT_MOSI` | FPGA 输出 |
| CS | 73 | `TFT_CS` | FPGA 输出 |
| DC | 74 | `TFT_DC` | FPGA 输出 |
| RST | 75 | `TFT_RST` | FPGA 输出 |
| BLK / LED | 76 | `TFT_BL` | FPGA 输出 |
| 电源 | - | `+3V3` | 3.3V |
| 地 | - | `GND` | 地 |

> ⚠️ **PIN71 / PIN72 互斥**：这两个引脚在最终方案中是 TFT 的 `TFT_SCLK` / `TFT_MOSI`。
> 开发期使用的旧 1.3 寸 OLED 调试屏（见 `docs/12_OLED实验记录.md`）同样占用
> SCL=PIN71、SDA=PIN72，因此**同一个工程不能同时连接 OLED 和 TFT，只能二选一**。
> 使用 OLED 的工程（`oled_demo` / `timbre_fx_demo` / 后续 `p5c_sonar_demo`）一律视为
> **开发期调试用途，不能作为最终引脚方案**；最终方案以 TFT 为准。

### 4.2 ADS1115 与效果旋钮

两个 ADS1115 共用 I2C：

| 信号 | FPGA 引脚 | 网络名 |
|---|---:|---|
| SCL | 77 | `I2C_SCL` |
| SDA | 85 | `I2C_SDA` |

ADS1115 #1：

| 通道 | 连接 |
|---|---|
| A0 | K1 效果旋钮中心脚 |
| A1 | K2 效果旋钮中心脚 |
| A2 | K3 效果旋钮中心脚 |
| A3 | K4 效果旋钮中心脚 |
| ADDR | 接 `GND`，地址 `0x48` |
| ALRT | 不连接，原理图中使用非连接标识 |

ADS1115 #2：

| 通道 | 连接 |
|---|---|
| A0 | 摇杆 `VRX` |
| A1 | 摇杆 `VRY` |
| A2 | 摇杆按压信号，经上拉/电平确认后预留 |
| A3 | 备用模拟通道 |
| ADDR | 接 `+3V3`，地址 `0x49` |
| ALRT | 不连接，原理图中使用非连接标识 |

v1.0 语义映射：

```text
VRX -> pitch_bend      左右：Pitch Bend / 手动颤音
VRY -> strum_interval  前后：和弦触发时锁存，决定扫弦 / 琶音错开时间
SW  -> 预留，不作为 v1.0 必需输入
```

摇杆前后是一条“扫弦时间”轴，不把前、后分别算作两个独立维度。

### 4.3 旋转编码器

当前实物的丝印信号为 `A / C / B / VCC / GND`。这里的接线关系按丝印名称
建立，不把该列表当作尚未核实的实物排针脚序：

```text
A   -> PIN25 -> ENC_A
B   -> PIN27 -> ENC_B
C   -> GND
VCC -> +3V3
GND -> GND
```

该模块的按压开关没有单独引出，因此 `VCC/GND` 不能当成 `SW` 使用。
Major / Minor 使用独立 `KEY_SCALE` 按键或板载 S2 切换。

A、B 可使用 FPGA 内部上拉；如果模块的 VCC 已经连接内部上拉，则不需要
再增加外部上拉。

如果以后换成明确带 `SW` 或 `SW1/SW2` 的编码器，可以保留
`KEY_SCALE` 作为并列功能，或将开关改接到 `PIN31`。

### 4.4 功能按键

每个按键一端接对应网络，另一端接 `GND`。FPGA 输入启用内部上拉。

| 功能 | FPGA 引脚 | 网络名 |
|---|---:|---|
| 音色切换 | 28 | `KEY_TIMBRE` |
| 独奏/和弦 | 29 | `KEY_MODE` |
| 效果器切换 | 30 | `KEY_FX` |
| Major/Minor | 31 | `KEY_SCALE` |

四个按键可直接选用 `B3F-4055` 或同类常开、自复位轻触开关。
不增加 RC、施密特触发器或专用消抖芯片，按键直接接 `GND`，
由 FPGA 内部上拉保持高电平。

消抖在 RTL 中完成，机械抖动通过约 `10 ms - 20 ms` 的稳定计数窗口过滤。
RTL 逻辑按低电平有效处理：

```text
按键松开 -> 1
按键按下 -> 0
```

若选用四脚轻触开关，原理图只需按一个常开开关连接；但 PCB 封装必须确认
四脚之间的内部等效关系，并把应该短接的两组端子按 datasheet 连接，不能
仅凭封装脚号猜测。

### 4.5 超声波

| 信号 | FPGA 引脚 | 网络名 |
|---|---:|---|
| TRIG | 26 | `ULTRA_TRIG` |
| ECHO | 80 | `ULTRA_ECHO` |
| 电源 | - | `+3V3` |
| 地 | - | `GND` |

必须使用 `HC-SR04P` 或确认 Echo 为 3.3V。普通 5V 版必须做电平保护
（分压或电平转换），不得直接把 5V Echo 接到 `PIN80`。

v1.0 语义映射：

```text
手距靠近 -> velocity / expression 增大
手距远离 -> velocity / expression 减小
```

note-on 时锁存一次 `velocity`；持续按住时更新平滑后的 `expression`。超声波
不直接驱动滑音，更新率约 10–20 Hz。

### 4.6 触摸多路复用器

三片 CD74HC4067 共用地址线：

| 信号 | FPGA 引脚 | 网络名 |
|---|---:|---|
| S0 | 41 | `MUX_S0` |
| S1 | 42 | `MUX_S1` |
| S2 | 48 | `MUX_S2` |
| S3 | 49 | `MUX_S3` |

公共模拟端（模块丝印通常为 `SIG`，芯片资料记为 `I/O`）：

| 模块 | 用途 | FPGA 引脚 | 网络名 |
|---|---|---:|---|
| 内圈模块 | 内圈 12 扇区 | 52 | `TOUCH_INNER` |
| 外圈模块 | 外圈 12 扇区 | 53 | `TOUCH_OUTER` |
| 第三圈预留模块 | 第三圈预留 | 86 | `TOUCH_AUX` |

三片 CD74HC4067 的 `/EN` 可以接地，当前不需要单独 FPGA 控制。

成品模块本体不会印 `U1/U2/U3`。本工程原理图统一使用
`J_MUX_INNER`、`J_MUX_OUTER`、`J_MUX_AUX` 作为母板侧位号；三片模块
按各自 `SIG` 连接的母板网络区分用途。

CD74HC4067 的芯片级功能名称为 `C0-C15 / S0-S3 / E / I/O / VCC / GND`。
成品模块通常会把 `E` 印成 `EN`、把 `I/O` 印成 `SIG`，但不同厂家的
模块排针布局可能不同。模块按功能名称建立以下网络连接：

| 模块引脚 | 母板网络名 | 说明 |
|---|---|---|
| `C0-C11` | `TOUCH_INNER_C0..C11` 等 | 每片接对应圆环的 12 个扇区 |
| `C12-C15` | `TOUCH_*_SPARE` | 预留通道 |
| `S0` | `MUX_S0` | 三片共用 |
| `S1` | `MUX_S1` | 三片共用 |
| `S2` | `MUX_S2` | 三片共用 |
| `S3` | `MUX_S3` | 三片共用 |
| `EN` | `GND` | 低电平使能 |
| `SIG` | `TOUCH_INNER` / `TOUCH_OUTER` / `TOUCH_AUX` | 每片独立 |
| `VCC` | `+3V3` | 3.3V |
| `GND` | `GND` | 地 |

下面的 `1..24` 只是“芯片常见连续排布”的示例，**不是本项目已经确认的
模块排针脚号**。只有实物丝印、1 脚方向和连续性都与该示例一致时才能采用；
如果模块是拆分布局、双排针或顺序不同，应以实物的“丝印 -> 脚号”表为准。

```text
1..16  -> C0..C15
17     -> S0
18     -> S1
19     -> S2
20     -> S3
21     -> EN
22     -> SIG
23     -> VCC
24     -> GND
```

如果实物丝印实际写作 `S10`，先不要按上表猜测。应查模块资料并测量它与
CD74HC4067 公共模拟端的连通关系；只有确认它就是芯片的 `I/O` 公共端后，
才能把它当作 `SIG` 使用。

### 4.7 LED 与 WS2812

| 功能 | FPGA 引脚 | 网络名 |
|---|---:|---|
| 板载 LED0 | 15 | `LED0` |
| 板载 LED1 | 16 | `LED1` |
| 板载 LED2 | 17 | `LED2` |
| 板载 LED3 | 18 | `LED3` |
| 板载 LED4 | 19 | `LED4` |
| 板载 LED5 / 外圈数据 | 20 | `LED_RING_DIN` |
| 板载 WS2812 | 79 | `STATUS_WS2812` |

外圈 WS2812 使用独立 `+5V` 供电，数据建议经过 `74AHCT125` 从 3.3V 转换到 5V。
PIN20 同时连接板载 LED5，因此 LED5 会随 WS2812 数据闪烁。

母板原理图中不需要重复放置以下器件，因为它们已经焊接在 Tang Nano 20K
核心板上：

- `LED0-LED5`
- `STATUS_WS2812`

核心板连接器仍保留这些引脚，用于在原理图中记录 FPGA 网络；母板可以将其
视为“核心板内部已经连接”。外圈 LED 环不是板载器件，需要在母板上保留
`J_RING`、5V 电源和电平转换电路。

## 6. 重要限制

- 34 个排针 IO 已全部分配，没有额外空闲 IO。
- 模块实物到货后如果排针顺序不同，只调整母板连接器或转接线，不改 FPGA 侧网络名。
- 芯片封装脚号、核心板排针脚号和成品模块排针脚号是三个独立层次，禁止互相套用。
- 每个模块实例都必须单独填写实物排针脚号；同型号模块也应抽查 1 脚方向和关键电源脚。
- 若 CD74HC4067 模块丝印为 `S10`，先用资料和万用表确认其功能，再决定是否按 `SIG` 接入。
- ADS1115 的逻辑电源使用 `+3V3`。
- KY-023 摇杆使用 `+3V3`，避免输出超过 FPGA 的 3.3V 模拟范围。
- `J_CORE_B-20` 是核心板提供的 5V 来源；若改用外部 5V，必须先断开核心板 5V 跳线，禁止两个 5V 源直接并联。
- `PIN71` / `PIN72` 被 TFT（`TFT_SCLK` / `TFT_MOSI`）与开发期 OLED 调试屏共用，
  **同一工程不得同时接入两者**；OLED 仅用于开发调试，最终方案以 TFT 为准。
- WS2812 的 5V 电源必须与 FPGA 共地。
- `TFT_BL` 若模块背光电流较大，需要增加三极管或 MOSFET 驱动，不能直接由 FPGA IO 供电。
