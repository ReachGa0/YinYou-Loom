## 1. 修复项一：PIN27 独奏 / 和弦模式切换

**现象**：接在 PIN27 的开关拨动后没有任何反应。

**根因（已确认）**：当前构建里 **PIN27 根本没有被使用**。上一版它曾是 PLAY/TEST 模式开关
（`key_mode_n`），改成和弦模式时我把它从顶层端口与 `p6_test_demo.cst` 里一起删掉了。

**务必不要再踩的旧坑**：上一版的模式切换守卫写的是

```verilog
if (mode_press_pulse[0] && (pressed == 4'b0000) && (voice_busy == 4'b0000))
```

而 `voice_adsr.v` 实测在所有非空闲状态（ATTACK / DECAY / **SUSTAIN** / RELEASE）都 `busy = 1'b1`，
所以只要有音在持续发声，切换条件永远不成立 → 模式锁死。**新实现禁止用 `voice_busy` 做阻断条件。**

**方案**

1. `fpga/p6_test_demo/src/p6_test_demo.cst` 加回 `key_mode_n = PIN27`（低有效、上拉）；
2. `rtl/p6_test_demo_top.v` 加 `key_scan #(.KEYS(1))` 与 `mode_sel` 寄存器（0=独奏，1=和弦）；
3. 切换采用**请求 + 延后生效**（与音色切换同一写法）：按下即记录请求值，等 `voice_busy == 4'b0000` 时自动搬过去。
   这样"按住音时拨开关"也不会没反应，只是稍后生效；
4. 语义：独奏 = 每键单音 C4/E4/G4/B4（沿用 `input_map.v`）；和弦 = 每键大三和弦（沿用 `chord_map.v`）；
5. OLED 第 1 行区分 `SOLO MODE` / `CHORD MODE`；LED 增加一位指示（LED0 亮 = 和弦模式）。

**验收**：按住任何键时拨动 PIN27 开关，松手后模式与 OLED/LED 一致；独奏与和弦音数分别为 1 / 3。

## 2. 修复项二：正弦和弦 + 合唱破音

**现象**：开启合唱后，正弦三音和弦有明显破音；方波暂不处理（本身听感就燥）。

**已排除**：`chorus.v` **没有忘记除 2**，源码是

```verilog
wire signed [SAMPLE_W:0] mix_sum = {dry_hold[15], dry_hold} + {delayed_q[15], delayed_q};
...
sample_out <= mix_sum >>> 1;      // 50% dry + 50% wet，已平均
```

17 位中间和有足够余量（±65535），不会溢出；50/50 平均也不会超过输入峰值。

**当前最可能的根因（待仿真验证）**：数字端电平已经**贴着满幅**。
三音和弦时 mixer 的归一化系数是 `21/64 ≈ 0.328`，每声部满幅 32767 → 三者相加约为
`32767 × 0.328 × 3 ≈ 32.2k`，即约 **98% 满幅**。这个电平经 I2S 送到 MAX98357A，
在功放增益 + 8Ω 小喇叭这条链路里**极易在模拟端削顶**；合唱让复合波形更复杂（拍频、梳状起伏），
听感上会更早暴露成"破音"。

**验证步骤（先做，再改）**

1. 用仿真导出 `mix_sample`（合唱前）与 `fx_sample`（合唱后）两段 wav，统计峰值与触顶样本数；
2. 若数字端无触顶 → 确认是模拟端余量不足，走下面的修复；
3. 若数字端确实触顶 → 说明还有别处的加法未做缩放，再定位。

**修复候选（按推荐顺序）**

| | 做法 | 影响 |
|---|---|---|
| 甲（推荐先试） | demo 顶层把 `SUSTAIN_LEVEL` 从 `16'd32768` 降到 `16'd16384`（约 −6 dB） | 只改一个参数，不动任何模块；音量变小一点 |
| 乙 | demo 顶层在 chorus 之后加总线 `>>> 1`（固定 −6 dB） | 只改顶层连线；同样不动共享模块 |
| 丙 | 给 chorus 输出加限幅 | 会改变音色，且治标不治本，不推荐 |

**验收**：正弦三音和弦 + 合唱，在按键全按下的最大音量下无明显破音；关闭合唱时音量与音色仍正常。

## 3. 修复项三：和弦"最近按下优先"逻辑（已选定方案甲）

**目标语义**（用户描述）：同一时刻只有一个和弦在响，最近按下的键优先；
按住 A 再按 B → 响 B；松开 B 而 A 仍按着 → 回到 A 的和弦。

**实现方案**

1. `chord_map.v` 的输入从"按下/松开脉冲"改为**按键电平 `pressed[3:0]`**（顶层已有），
   顺带消除"三音发射途中松手"的理论窗口；
2. 每个键一个**按下时间戳**（4 位递增计数器），当前应响的键 = 仍按着且时间戳最大的那个；
3. 状态机：`当前键变化 → 释放旧和弦（3×note_off，脉冲间空一拍）→ 等 voice_busy == 4'b0000
   → 起新和弦（3×note_on）→ 保持`；没有键按下 → 全部释放 → 空闲；
4. 释放等待带来的换和弦延迟约 **34 ms**（`r_step = 20`、满幅 32768 算），听感类似钢琴换和弦；
   若上板后觉得拖沓，再考虑给 `synth_engine` 加 `R_STEP` 参数（共享模块，需单独评估）。

**因此不再需要**：扩到 8 声部、mixer 归一化扩档（原计划"甲"）、键级 note_id 编码、OLED 5–8 字形、
状态位重分配。VOICES 保持 4，OLED 继续显示 `VOICE n/4`。

**验收**：A 按住 → 按 B → 松 B 能干净回到 A 的和弦；快速连按不丢音、不卡音、无爆音；
同时按键数不超过 3。
