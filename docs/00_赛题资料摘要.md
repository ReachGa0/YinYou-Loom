1. **资格审查**：按信息完整度、项目创新性、科学性、工程可行性、**FPGA 平台适用度** 判定。
2. **初赛**：提交作品报告 + 视频，专家线上评审 → 入围决赛名单（公示 3 天）。
3. **决赛**：含 **FPGA 基础编程设计能力考核**（通过才获决赛评奖资格）→ 现场评审：作品介绍、演示、专家提问。

> 注意：**资格审查阶段就会看"创新性 + 工程可行性 + FPGA 平台适用度"**，选题要早定、文档要早写。

**Tang Nano 20K（本队平台）**
- 芯片 **GW2AR-LV18QN88C8/I7**
- **20736 个 LUT4 / 15552 个 FF**
- 2 个 PLL，多个 DSP（18×18 乘法）
- 板载 **BL616**：JTAG 下载器 + 与 FPGA 通信的串口

## 三、选题二原文（本队赛题）

### 设计要求
设计一套基于 FPGA 的**实时多音色合成电子乐器引擎**。
- 依托电容触摸、光电感应、压力检测、无接触手势等**任意自研交互方案**，实现 **≥2 个独立可控演奏维度**的动作采集，精准识别**选音、和弦、触发、拨弦**等演奏指令。
- 以 FPGA 为核心并行计算平台，在**硬件逻辑层**搭建专属实时音频合成引擎，采用**波表采样、加法合成、FM 调频或物理建模**等任意合规算法，对演奏控制信号进行**逐样本、逐声部**实时音频运算。
- 最终通过 **I2S 接口输出音频至 DAC 解码发声**。
- 充分发挥 FPGA 并行流水线优势：高复音并发、多音色切换、多维表情调控、严格控制演奏延迟。

### 基础要求（必须做到）
1. **多维交互控制检测**：自主设计演奏交互形态，基于各类传感器实现演奏动作精准采集，支持**选音、触发、拨弦、力度感应**，**≥2 个独立可控维度**，交互逻辑灵敏稳定。
2. **FPGA 纯硬件实时音频合成**：完整音频生成通路**全部基于 FPGA HDL 硬件逻辑**实现，支持逐样本实时运算；算法任选；**控制信号 → 音频输出总延迟 ≤10ms**；杜绝软件串行运算滞后。
3. **合规实时发声与多复音**：
   - **基础复音数 ≥4**，≥4 路独立声部同时并发发声。
   - **合规红线**：所有输出音频必须由 FPGA 根据实时演奏指令**逐音、逐样本实时生成**；支持**单音实时变调、ADSR 包络调控、多声部实时混音**。
   - **严禁**直接播放预录 PCM 音频、预置推流、整段录音触发。

### 拓展要求（加分项）
1. **超高规模并行合成引擎**：复音数 **≥32**，或单音**加法合成分量 ≥32 路**，或多条并行物理建模运算单元。最大化发挥 FPGA 并行计算优势。
2. **多维表情控制与音频效果处理**：**≥3 维**演奏表情调控逻辑（力度动态、滑音、颤音等）；**≥2 种乐器音色**自由切换；FPGA 硬件内部实现**混响、延迟、合唱**等数字音频效果器。
3. **极致低延迟与实时视听反馈**：延迟压缩至 **≤5ms** 且**确定性无抖动**；基于 FPGA 硬件逻辑实时生成可视化反馈（LED 演奏指引、**李萨如图形**、实时频谱、波形显示）。
4. **智能联动与脱机拓展**：脱机演奏 LED 曲目指引；可搭载**蓝牙模块与手机 App 联动**（在线曲谱下载、演奏键位自定义、演奏录音回传）。

### 核心评分规则与现场验证标准（关键！）
1. **振荡器统计规则**：独立发声单元 = 包含**独立相位累加器 + 频率调控 + 包络控制**的完整振荡器。
   - 单波表采样查表**不计多谐波数量**，仅计单个振荡器；
   - **加法合成按运算分量统计**；**FM 按调制运算器统计**；**物理建模按并行弦/模态单元统计**。
2. **系统吞吐量指标**：以「**同时活跃可闻独立振荡器总数 × 实际音频输出采样率**」为核心评分依据，**过采样不叠加加分**。
3. **现场验证要求**：支持**测试模式**输出多路不同频率音频，频谱可观测到对应数量**独立谱峰**；同时可通过 **RTL 代码佐证纯硬件实时合成通路**，验证无预录音频播放行为。
