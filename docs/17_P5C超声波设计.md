## 1. 目标

P5C 先完成一个可独立仿真的超声波测距模块：

- 使用成品 `HC-SR04P` 超声波模块。
- FPGA 产生 TRIG 脉冲并测量 ECHO 高电平时间。
- 输出以毫米为单位的距离、有效标志和故障标志。
- 先做独立 `p5c_sonar_demo`，用旧 1.3 寸 OLED 显示距离，不修改正式 `loom_top`。
- 距离稳定后，再由 `input_map` 映射为 `velocity / expression`。

本文件只定义 P5C 的测距模块和验证边界。力度平滑、死区和最终 `input_map` 合并属于后续任务。

## 2. 硬件与引脚

| 项目 | 约定 |
|---|---|
| 模块 | 优先 `HC-SR04P` 3.3V 版 |
| 供电 | `+3V3` |
| TRIG | FPGA `PIN26`，网络名 `ULTRA_TRIG` |
| ECHO | FPGA `PIN80`，网络名 `ULTRA_ECHO` |
| 地 | 与 FPGA 共地 |

普通 5V `HC-SR04` 不能直接把 Echo 接到 FPGA。必须做电平保护，分压或电平转换均可；
`1kΩ + 2kΩ` 在 5.25V 电源下可能输出约 3.5V，不是安全余量。上电前应实际测量
Echo 高电平，确认不超过 3.3V 后再接入 PIN80。详见 `docs/11`。

`HC-SR04P` 在 3.3V 下的测距范围、重复性和抗干扰表现仍需实机确认，不能把
“3.3V 版本一定和 5V 版本表现一致”当作结论。

## 3. 模块接口

接口冻结如下。若实现中必须改动，应先更新本文件并重新确认，不能只改代码：

```verilog
module sonar_range #(
    parameter CLK_MHZ     = 72,        // 当前设计只保证整数 MHz 输入
    parameter TRIG_US     = 12,        // TRIG 高电平宽度，规格要求 >=10us
    parameter PERIOD_US   = 70_000,    // 两次 TRIG 启动间隔下限，>=60ms
    parameter TIMEOUT_US  = 30_000,    // 等待 ECHO 或测量 ECHO 的单次超时
    parameter STUCK_US    = 100_000,   // WAIT_LO 有界等待时间
    parameter MIN_ECHO_US = 50,        // 低于此值视为毛刺
    parameter MAX_DIST_MM = 4500       // 距离上限，超出则判无效
)(
    input  wire        clk,
    input  wire        rst_n,
    output reg         trig,           // 到 PIN26
    input  wire        echo,           // 来自 PIN80，异步输入
    output reg  [15:0] distance_mm,    // 0-4500；复位时为 16'hFFFF
    output reg         valid,          // 有效标志；置 1 后保持到下次进入 S_TRIG
    output reg         fault,          // ECHO 卡高锁存标志，成功测量后清除
    output reg  [7:0]  stuck_cnt       // 卡高次数，饱和到 255，调试用
);
```

### 3.1 单位选择

输出使用 `mm`。10-50cm 的映射区间如果只保留 cm，动态范围较粗；mm 不增加硬件成本，
OLED 显示时用 `mm / 10` 得到 cm。

### 3.2 时钟约束

当前主时钟为 72MHz。模块用 `CLK_MHZ` 生成 1MHz 计数节拍，所有时间参数都用微秒表示。
如果以后把主时钟改为 50.4MHz，不能把 `CLK_MHZ` 简单写成 50 后认为没有误差；
必须重新确认整数分频误差，或者改成带分数节拍的实现。

## 4. 状态机

```text
S_IDLE -- 周期门限到，valid<=0 --> S_TRIG
S_TRIG -- trig=1 持续 TRIG_US，然后回低 --> S_WAIT_HI
S_WAIT_HI -- echo 为高 --> S_MEASURE
S_WAIT_HI -- TIMEOUT_US 且 echo 仍低 --> S_IDLE（本次无效）
S_MEASURE -- echo 下降沿 --> S_CALC
S_MEASURE -- TIMEOUT_US 且 echo 仍高 --> S_WAIT_LO（本次无效）
S_WAIT_LO -- echo 回低 --> S_IDLE
S_WAIT_LO -- STUCK_US 且 echo 仍高 --> S_IDLE（fault=1，stuck_cnt 饱和加一）
S_CALC -- 毛刺 / 上限校验通过 --> S_IDLE（更新距离，valid=1，fault=0）
S_CALC -- 校验失败 --> S_IDLE（valid=0，距离保持）
```

### 4.1 周期语义

`PERIOD_US` 是两次 TRIG 启动间隔的下限，不是固定周期。周期计时从每次 TRIG
启动开始，正常测量时实际间隔为：

```text
max(PERIOD_US, 本状态机从本次 TRIG 到下一次可触发所花的时间)
```

正常回波时约为 70ms，约 14.3Hz。ECHO 卡高时，状态机需要经过
`TIMEOUT_US + STUCK_US`，实际重试间隔会明显变长，这是预期的故障恢复行为。

### 4.2 ECHO 卡高处理

- `S_WAIT_HI` 不能只等上升沿，否则 ECHO 一开始就是高电平时会永远等不到边沿。
- `S_WAIT_LO` 不能无限等待，否则 ECHO 卡高会让整个模块停止测量。
- `STUCK_US` 到且 ECHO 仍高时，置 `fault=1`，记录 `stuck_cnt`，然后回到 `S_IDLE`。
- `fault` 不能在回 `S_IDLE` 时自动清除。只有后续测量成功，才同时清除 `fault`。
- 卡高恢复期间继续按状态机允许的最快周期重试，不需要复位 FPGA。

### 4.3 输出语义

| 信号 | 语义 |
|---|---|
| `distance_mm` | 最近一次有效距离；无效测量时保持不变 |
| `valid` | 本次测量完成且通过校验时为 1；置 1 后**保持到下一次进入 `S_TRIG`**，不是单周期脉冲 |
| `fault` | ECHO 卡高锁存；成功测量后清除 |
| `stuck_cnt` | 卡高次数，饱和到 255，仅用于调试 |

上电复位后：

```text
trig        = 0
distance_mm = 16'hFFFF
valid       = 0
fault       = 0
stuck_cnt   = 0
```

每次进入 `S_TRIG` 时立即令 `valid=0`。`valid` 是电平型标志，置 1 后保持到下一次
进入 `S_TRIG`，所以上层可以按自己的节奏采样，但**必须只在 `valid=1` 时使用
`distance_mm`**，不能把 `16'hFFFF` 或上一次的旧距离当成当前测量结果。

### 4.4 时间基与时间戳刷新

模块内部只有一个自由运行的微秒时基：`CLK_MHZ = 72` 时每 72 个时钟产生一个 1 µs
节拍，`us_cnt` 在该节拍上累加。72 → 1 是整数分频，节拍精确为 1 µs，无累积误差。
所有超时判定统一写成回绕安全的形式 `(us_cnt - t_ref) >= LIMIT`；计数器和时间戳
统一使用显式 32 位宽度，避免宽度与符号警告。

时间戳**只在状态转移那一拍单次刷新**，禁止在 `S_WAIT_HI` / `S_MEASURE` / `S_WAIT_LO`
内部每个时钟周期无条件刷新，否则超时判定会失效，回波时间也可能恒为 0：

| 时间戳 | 刷新时机 | 用途 |
|---|---|---|
| `t_trig_start` | 进入 `S_TRIG` 时（`S_IDLE -> S_TRIG` 转移） | `S_TRIG` 的 TRIG 宽度判定、`S_IDLE` 的周期下限判定 |
| `t_state` | 仅在 `S_TRIG -> S_WAIT_HI` 和 `S_MEASURE -> S_WAIT_LO` 转移时 | `S_WAIT_HI`、`S_WAIT_LO` 的有界超时判定 |
| `t_echo_rise` | 仅在 `S_WAIT_HI -> S_MEASURE` 转移时 | 回波起点；同时作为 `S_MEASURE` 的 `TIMEOUT_US` 基准 |
| `t_echo_fall` | 仅在 `S_MEASURE` 检测到下降沿时 | 回波终点，`echo_us = t_echo_fall - t_echo_rise` |

`S_MEASURE` 的超时基准取 `t_echo_rise`，语义是“回波高电平最长 `TIMEOUT_US`”，与
第 4 节的状态机描述一致。4500mm 对应约 26.3ms 回波，距 30ms 超时仍有约 3.7ms 余量。

### 4.5 已知残余风险（v1.0 不修）

`S_WAIT_HI` 按 ECHO **电平**判定，因此当 ECHO 在 TRIG 之前就已经为高（接线错误、
模块故障，或上一轮回波残留）时，`S_MEASURE` 会从“进入该状态的时刻”开始计时，
有可能换算出一个**看起来合法、实际错误**的距离（例如 ECHO 提前为高、约 1ms 后
回落时会得到约 171mm 的假距离）。

- 本设计**不增加 `rise_seen` 标志**，不扩大已经冻结的状态机。
- 持续卡高的场景最终仍会被 `STUCK_US` 判为 `fault`；落在 `MIN_ECHO_US` 与
  `MAX_DIST_MM` 之外的异常值也会被过滤，但**不能完全排除**落在有效区间内的假读数。
- 该风险在此登记，供 P5C.2（力度 / 动态映射）参考；如实机出现假距离，再单独评估
  是否引入 `rise_seen`。

## 5. 距离换算

ECHO 高电平单位是微秒，距离按 20°C 空气中声速约 343m/s 计算，并采用四舍五入：

```text
distance_mm = ((echo_us * 11233) + 32'h8000) >> 16
```

常数 `11233 / 65536 ≈ 0.171402 mm/µs`，对应声速约 **342.8 m/s**，是 343m/s 的定点
近似（若按 `0.1715 mm/µs` 反推应为 11239，本设计固定使用已冻结的 11233，两者相差
约 0.06%，折算到 50cm 约 0.3mm、4500mm 约 2.6mm），**不是 `0.1715 mm/µs`**。

采用四舍五入后，116 / 583 / 2915 µs 分别换算出 **20 / 100 / 500 mm**，与第 6 节用例
的期望值一致；若改用截断则会得到 19 / 99 / 499 mm。

实现时应使用足够的中间位宽。`echo_us` 最大约 30000 时，`echo_us * 11233` 最大为
336,990,000，**需要 29 位以上；实现统一使用 32 位中间积**，不能直接存入 16 位寄存器。

温度变化带来的声速误差不属于 v1.0 修正范围；如果后续需要提高精度，再增加温度补偿。

## 6. 仿真验证计划

测试文件计划为 `sim/tb_sonar_range.v`。先用参数缩短仿真时间，再至少跑一组
接近 72MHz 的真实时钟配置，检查分频和边沿处理。

| 编号 | 用例 | 期望 |
|---|---|---|
| 1 | 583us 回波，约 10cm | `valid=1`，`distance_mm` 约为 100 |
| 2 | 116us / 2915us，约 2cm / 50cm | 结果约为 20mm / 500mm |
| 3 | 先完成一次有效测量，再让 ECHO 全程为低 | `valid=0`，距离保持上一次值 |
| 4 | 38ms 长高脉冲模拟部分模块的无回波行为 | `valid=0`，单次事件不置 `fault` |
| 5 | ECHO 持续高超过 100ms | 状态机不死锁，`fault=1`，后续 TRIG 继续发出 |
| 6 | 卡高后 ECHO 回落并给出正常回波 | 恢复 `valid=1`，`fault` 自动清零 |
| 7 | ECHO 出现一周期毛刺 | 不更新有效距离 |
| 8 | ECHO 边沿在时钟边沿附近变化 | 两级同步后边沿行为确定，不重复计数 |
| 9 | 复位后首次无回波 | `valid=0`，不得把 `distance_mm=16'hFFFF` 当距离 |
| 10 | 超过 `MAX_DIST_MM` 的换算结果 | `valid=0`，不更新距离 |

全局断言：

- TRIG 高电平至少 10 µs；按 1 µs 粒度实现与断言（`TRIG_US=12` 留有余量），
  不断言、也不声称 ns 级宽度或抖动。
- 相邻 TRIG 启动间隔至少 60ms；故障恢复时允许更长。
- `valid=0` 时，上层逻辑不得使用 `distance_mm`。

仿真只能验证两级同步和边沿计数的数字行为，不能证明真实器件的亚稳态概率。
亚稳态风险应由两级同步器结构和时序约束处理。
