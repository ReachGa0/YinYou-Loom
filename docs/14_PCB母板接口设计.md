## 1. 设计边界

第一版 PCB 是一块**模块化母板**，不把裸芯片、音频功放或复杂模拟前端直接放到板上。

母板只负责：

- 固定并转接 Sipeed Tang Nano 20K。
- 分配 `3V3`、`5V` 和 `GND`。
- 为成品模块提供带丝印的防插错接口。
- 引出触摸电极、按键、测试点和调试信号。
- 保留核心板 USB-C、HDMI 等接口的操作空间。

第一版不负责：

- 重画 FPGA 最小系统。
- 在 PCB 上重新实现 MAX98357A、BL616 或电源核心。
- 在模块尺寸到货确认前固定最终外壳和孔位。

## 2. Tang Nano 20K 安装方式

Tang Nano 20K 本体不焊接在母板上，而是通过两条 **1x20、2.54 mm** 母座插接：

| 位号 | 类型 | 说明 |
|---|---|---|
| `J_CORE_A` | 1x20 母座 | 对应核心板一条 20 pin 排针 |
| `J_CORE_B` | 1x20 母座 | 对应核心板另一条 20 pin 排针 |

注意：

- 核心板是两条独立的 `1x20` 排针，不应使用普通 `2x20` 双排母座代替。
- 原理图符号中的物理顺序必须与实物从上到下或从左到右一致。
- 焊接前先用实物核对方向，不能只按网上图片判断。
- 母板丝印必须标出 `USB` 和 `HDMI` 方向，防止核心板反插。

核心板资料给出的排针引线顺序以
`reference/Sipeed Tang nano 20K Datasheet V1.3-en_US.pdf` 第 5 页为准。
建立正式原理图符号时，必须逐个复核该页和实物丝印。

### 2.1 建议的统一方向

先不要依赖嘉立创连接器符号自带的 `1..20` 含义，而要人为规定：

> 设计目标：两条核心板母座的 `1` 脚都放在 Tang Nano 20K 的 USB-C 一端。

注意：原理图里的“屏幕绝对位置”本身不参与电气连接，真正参与连接的是
**引脚编号到网络的映射**。连接器旋转 180 度并不是绝对错误，只要最后 PCB
封装中位于 USB 端的焊盘编号也保持一致即可。为了减少出错，第一版仍建议
两条排针采用同样的方向。

按这个方向，两条排针从 USB 一侧到 HDMI 一侧的电源脚和地脚为：

| 排针 | 20 个脚从 USB 端到 HDMI 端的编号 | 电源和地 |
|---|---|---|
| `J_CORE_A` | `73,74,75,85,77,15,16,27,28,25,26,29,30,31,17,20,19,18,3V3,GND` | `19 = +3V3`，`20 = GND` |
| `J_CORE_B` | `5V,GND,76,80,42,41,56,54,51,48,55,49,86,79,GND,3V3,72,71,53,52` | `1 = +5V`，`2 = GND`，`15 = GND`，`16 = +3V3` |

如果两条排针都采用统一方向，`J_CORE_A` 的 1 脚和 `J_CORE_B` 的 1 脚
都在 USB-C 一端。如果连接器符号被旋转 180 度，脚号顺序会反过来，电源
必须重新对应。

如果把 `J_CORE_B` 保持为 `20` 脚在上、`1` 脚在下，则 USB 端对应的是
`20` 脚，正确连接应改为：

```text
J_CORE_B  20 -> +5V
J_CORE_B  19 -> GND
J_CORE_B   6 -> GND
J_CORE_B   5 -> +3V3
```

这和对齐方向后的 `1/2/15/16` 脚表达的是同样四个物理位置，只是连接器
符号的编号方向不同。最终必须让 PCB 焊盘编号和这里选定的方案一致。

当前母板原理图采用 `J_CORE_B` 反向放置，因此第一版至少应接住：

```text
J_CORE_A  19 -> +3V3
J_CORE_A  20 -> GND

J_CORE_B  20 -> +5V
J_CORE_B  19 -> GND
J_CORE_B   6 -> GND
J_CORE_B   5 -> +3V3
```

如果以后把 `J_CORE_B` 改成与 `J_CORE_A` 相同的方向，则对应的电源脚变为
`1/2/15/16`。两种表示不能混用；原理图和 PCB 封装必须采用同一套脚号方向。
重复出现的电源脚要全部接入，不能只接其中一个。

## 3. 电源分区

| 电网 | 默认来源 | 供电对象 | 规则 |
|---|---|---|---|
| `+3V3` | Tang Nano 20K 的 3V3 引脚 | TFT、ADS1115、CD74HC4067、摇杆、超声波 | 所有逻辑模块必须为 3.3V 逻辑 |
| `+5V` | 核心板 `J_CORE_B-20`，或外部 5V 输入 | WS2812、可能的模块背光 | 外部 5V 与核心板 5V 不得硬短接；必须通过跳线、肖特基/理想二极管或电源选择电路 |
| `GND` | 全部电源和模块共地 | 所有设备 | 不允许模块各自形成独立地 |

开发阶段优先由 Tang Nano 20K 的 USB-C 供电，母板只取 `+3V3`。如果 WS2812
亮度较高或外接模块较多，再接入独立 `5V 2A` 电源，并确保共地。

以下事项在原理图中必须保留为明确设计：

- 每个模块接口附近放置 `0.1 uF` 去耦电容。
- `5V` 轨放置至少一个 `100 uF` 以上的体电容。
- `5V` 核心板连接使用跳线、0 欧姆电阻或电源选择电路，方便隔离故障并防止两个 5V 源互相倒灌。
- WS2812 数据从 FPGA 的 3.3V 到 5V 需要电平转换；可在板上预留
  `74AHCT125` 模块接口，不直接把 3.3V 数据线当 5V 信号使用。

## 4. 模块接口草案

接口先按“功能 + 唯一防插错连接器”设计，不按杜邦线颜色设计。

本节的“顺序”只定义母板网络和模块丝印的对应关系，**不是芯片封装脚号，
也不是未经核实的模块排针脚号**。实物模块可能使用不同的排针排列、跳线、
双排针或拆分布局；正式画符号前必须记录实物 1 脚方向，并逐个填写
“模块丝印 -> 实物排针脚号 -> 母板网络”。

| 位号 | 接口 | 引脚数 | 母板信号约定（不定义实物排针号） |
|---|---|---:|---|
| `J_TFT` | 2.4 寸 **ST7789VW** SPI TFT | 8 | `GND / +3V3 / SCL / SDA / RES / DC / CS / BLK`（2026-10-12 实测确认，屏参见 docs/22） |
| `J_ADC_KNOB` | 4 个效果旋钮 ADS1115 | 10 | `3V3 / GND / SCL / SDA / ADDR / ALRT / A0 / A1 / A2 / A3` |
| `J_ADC_AXIS` | 摇杆与备用模拟量 ADS1115 | 10 | `3V3 / GND / SCL / SDA / ADDR / ALRT / A0 / A1 / A2 / A3` |
| `J_JOY` | KY-023 双轴摇杆 | 5 | `+3V3 / GND / VRX / VRY / SW` |
| `J_ENC` | EC11 调性编码器 | 5 | `A -> ENC_A`、`C -> GND`、`B -> ENC_B`、`VCC -> +3V3`、`GND -> GND` |
| `J_KEY1..J_KEY4` | 功能按键 | 每个 2 | `SIG / GND` |
| `J_ULTRA` | HC-SR04P 超声波 | 4 | `VCC / TRIG / ECHO / GND`，对应 `+3V3 / ULTRA_TRIG / ULTRA_ECHO / GND` |
| `J_RING` | 外圈 WS2812 | 3 | `+5V / GND / DIN` |
| `J_MUX_INNER` / `J_MUX_OUTER` / `J_MUX_AUX` | CD74HC4067 触摸多路复用器 | 以实物排针为准 | `C0-C15 / S0-S3 / EN / SIG / VCC / GND` 的网络功能 |
| `J_TOUCH_IN` | 24 路触摸电极排线 | 待定 | 内圈 12 / 外圈 12，第三圈预留 |

功能按键直接使用 FPGA 内部上拉，不增加硬件消抖器件；RTL 中以
`10 ms - 20 ms` 的稳定计数窗口完成软件消抖。

最终接口引脚顺序必须在模块到货后，以模块丝印、连续性测量和数据手册再次确认。
特别是 ADS1115、CD74HC4067 和 TFT 模块，不同厂家的排针顺序可能不同。
禁止把 CD74HC4067 芯片 DIP 封装的 `1..24` 脚号直接当作模块排针号。

## 5. 调试与测试点

母板至少保留以下测试点：

| 测试点 | 用途 |
|---|---|
| `TP_3V3` / `TP_5V` / `TP_GND` | 电源检查 |
| `TP_BCLK` / `TP_LRCK` / `TP_DIN` | I2S 波形检查 |
| `TP_UART_TX` / `TP_UART_RX` | 串口调试 |
| `TP_JTAG_*` | 仅在核心板排针无法直接访问时保留 |
| `TP_TOUCH_*` | 触摸原始波形与 RC 测量 |

测试点优先使用可夹探针的焊盘或测试环，不把测试点藏在模块下面。

## 6. 嘉立创 EDA 操作顺序（暂停，恢复 PCB 后执行）

### 第一步：只建立原理图骨架

1. 将工程命名为 `Loom_Carrier_V1`。
2. 新建原理图页和 PCB，先不要绘制最终板框。
3. 放两条 `1x20` 母座符号，命名为 `J_CORE_A` 和 `J_CORE_B`。
4. 建立 `+3V3`、`+5V`、`GND` 三个电源网络。
5. 先把核心板的电源和地脚接入网络，暂不连接其他信号。
6. 保存并运行 ERC，确认没有悬空电源网络。

这一阶段完成的标准是：原理图中有核心板接口、三个电源网络和可读的位号，
PCB 中还没有任何最终布局。

### 后续顺序

1. 按模块到货顺序补齐接口符号和丝印。
2. 逐模块记录丝印、1 脚方向、实物排针脚号，并填写到网络映射表。
3. 核对模块实物尺寸、排针方向和插拔空间。
4. 完成原理图 ERC，再进行 PCB 摆放。
5. 先摆核心板、电源入口和连接器，最后布置铜箔触摸走线。
6. 触摸模拟走线远离 I2S、晶振和 WS2812 电源线。

## 7. 当前禁止事项

- 不根据当前杜邦线颜色决定 PCB 网络。
- 不在模块尺寸到货前固定接口和外框位置。
- 不把 5V 信号直接接进 FPGA IO。
- 不让 WS2812 的大电流回路穿过触摸模拟地。
- 不把核心板的 5V、3V3 和外部电源同时无隔离地硬连接。
