## 2. RTL 信号路径

### 2.1 正式演奏

```text
key_n[6:0]
  → key_scan（10 ms 消抖）
  → input_map / chord_map
  → 演奏事件寄存一拍
  → synth_engine
      → voice_alloc
      → synth_top
          → voice_osc + voice（ADSR / 力度增益）
          → mixer
  → TONE 补偿
  → Y 轴 expression 增益
  → fx_engine（DRY / CHORUS / DELAY / REVERB）
  → wave_capture
  → i2s_tx
  → MAX98357A
```

摇杆链路：

```text
joy_x / joy_y（RC 网络）
  → rc_adc
  → joy_filter（3 点中值 + 1/8 低通）
      ├─ X → pitch_bend_map → synth voice_osc
      └─ Y → expression_map
                 ├─ velocity → note-on 时锁存到声部
                 └─ expression → 混音后总体增益
```

### 2.2 R3 测试模式

```text
PIN25 切换
  → test_mode_router
      → 等待正式演奏 voice_busy 全部清零
      → test_mode
  → 与演奏输入二选一
  → 同一个 synth_engine / voice_alloc / mixer
  → 测试模式绕过 TONE 补偿、expression 和 FX
  → i2s_tx
```

测试模式没有独立音频发生器，测试音和正常演奏使用同一套逐样本合成链路。

### 3.1 测试频率为什么选这些值

- 采样率为 48 kHz，FFT 计划点数为 4096；
- 频率栅格为 `48000 / 4096 = 11.71875 Hz`；
- 上述 32 个频率均为栅格整数倍，满足相干采样；
- `k` 全部取质数，质数之间不存在非平凡整数倍关系，可避免整数倍谐波重叠；
- `note_id = 80..111` 避开 A 加权补偿表，32 路测试音增益一致。

## 4. 延迟测量

### 4.1 测量边界

基础要求使用以下边界：

```text
T0：目标按键在物理引脚上完成最后一次机械抖动后的稳定有效电平
T1：I2S DIN 中第一次发送包含新音符的非零采样
延迟 = T1 − T0
```

该边界包含：

- 10 ms 按键消抖；
- 按键事件选择、频率计算和声部分配；
- ADSR 起音到首个非零样本；
- 混音、效果器和 I2S 发送。

该边界不包含：

- 手部机械运动时间；
- MAX98357A 的模拟重建延迟；
- 扬声器与空气传播时间。

如果还要测量“耳朵听到”的模拟延迟，应另列一组数据并明确包含 DAC/功放。

### 4.2 推荐仪器

- 两通道以上逻辑分析仪或示波器；
- 采样率不低于 10 MS/s；
- 通道 A：目标按键物理引脚；
- 通道 B：I2S DIN；
- 如仪器支持 I2S 解码，直接读取第一个包含目标音符的采样帧；
- 如不支持解码，保存原始波形并按 48 kHz 帧率人工核对。

### 4.3 测量步骤

1. 烧录当前 `p6_test_demo.fs`，等待 PLL 锁定和 UI 稳定。
2. 保持摇杆 Y 在固定位置，避免力度包络变化干扰找到首个非零样本。
3. 选择同一个音名键，至少完成 10 次独立按下。
4. 每次触发条件设为按键下降沿。
5. 找到按键最后一次机械抖动结束的稳定低电平作为 `T0`。
6. 找到 DIN 上第一个属于该音符的非零采样作为 `T1`。
7. 记录 `T1 − T0`，同时保留波形或截图路径。
8. 单独测试快速连奏、正常单按和长按，确认事件没有丢失。

## 5. 摇杆硬件装配

### 5.1 供电和 RC 网络

每轴使用同一套前级：

```text
摇杆电位器输出 ──[100k]──┬── FPGA 引脚
                         ├──[47k]── 3V3
                         └──[100nF]── GND
```

对应关系：

| 轴 | 电位器输出 | FPGA 引脚 |
|---|---|---:|
| X | VRX | 48 |
| Y | VRY | 49 |

### 5.2 强制检查

- 摇杆模块丝印 `+5V` 必须接开发板 **3V3**，不能接 5V；
- GND 必须与 FPGA 共地；
- VRX / VRY 不得直连 FPGA，必须经过 RC；
- `joy_x` / `joy_y` 约束为 `PULL_MODE=NONE`；
- 电容当前为 **100 nF**，不能用 10 µF 替代；
- 上电时摇杆应回中，不要按住或推到极限位置。
