## 1. 这份文档回答什么

当前方案层已经基本闭环，但还不能称为“合格成品”。本文件把 v1.0 要交付的

## 4. 冻结的输入语义

后续无论输入来自按键、摇杆、超声波还是触摸，都先转换成下列语义，再交给
`input_map` 和合成引擎。不要把这些逻辑直接写死到某个传感器模块里。

| 语义字段 | 含义 | v1.0 来源 |
|---|---|---|
| `note_select` | 选择音名 / 和弦根音 | 按键、后续触摸 |
| `trigger` | 开始新音符或和弦 | 按键、后续触摸 |
| `pluck` | 拨弦型包络事件 | MODE 的 PLUCK ONE / PLUCK TRI |
| `velocity` | 单次触发力度 | 摇杆 Y 位置（按下瞬间） |
| `expression` | 持续按住时的动态 | **摇杆 Y 连续值**（当前为混音后增益） |
| `pitch_bend` | 实时音高偏移 | 摇杆左右，**±1 半音** |
| `strum_interval` | 和弦内音符错开时间 | 后续增量（变阻器 / 摇杆组合） |
| `timbre` | 音色选择 | S1 循环 4 档 |
| `fx_bypass` | 效果选择 | S2 循环 4 档 |

### 4.1 摇杆左右：Pitch Bend

- 中心为 0，松开自动回中。
- 死区 150 计数，有效范围 **±1 半音**，输出经一阶低通。
- 实时改变相位增量或音高比例，不通过超声波参与快速音高控制。

### 4.2 摇杆前后：持续表情 / 动态

- 摇杆 Y 直接控制整体音量，**按住音时推摇杆也能实时变化**；
- 按下瞬间的 Y 值同时作为该声部的 note-on 力度；
- 当前增益约 **0.1–1.0**，减小/增大两段分开标定（增大段更陡）；
- 按键瞬间的音量由当时 Y 位置决定，相当于该音的 velocity；
- 已加一阶低通（约 8ms）与中位死区。

> 2026-10-24 起，摇杆先经过 3 点中值去尖峰，再进入低通。力度和 expression
> 在 `expression_map.v` 中分成两条语义，避免把持续音量误当成逐音力度。

### 4.3 超声波：已取消

**2026-10-23 与用户确认：v1.0 不使用超声波。** 赛题只要求“基于各类传感器”，
不强制超声波；摇杆 Y 已能提供力度 / 动态维度。

### 4.4 MODE 四档（2026-10-23 实现）

| MODE | 发声方式 |
|---|---|
| `ONE` | 单音、持续 |
| `TRI` | 三和弦、持续 |
| `PLUCK ONE` | 单音拨弦：短促起音 + 约 340ms 自然衰减，按住不放也会自动结束 |
| `PLUCK TRI` | 三和弦整体拨弦（三个音同时起音、一起衰减），不是分解和弦 |

**拨弦 ≠ 分解和弦**：拨弦是包络 / 发音方式；分解和弦（琶音）是音符时序，
对应 `strum_interval`，留作后续增量。

## 5. 后续增量功能的边界

这些功能后续可以加，不应推翻音频核心：

- 自研铜箔触摸圆环：只新增输入源，仍输出 `note_select / trigger / pluck`。
- 2.4 寸 TFT：只读取状态，不反向修改音频参数。
- 延迟 / 混响：接入现有效果器链路，先保证合唱旁路稳定。
- WS2812 / LED 曲目指引：只消费演奏和测试状态。
- 更高复音：依赖 `VOICES` 参数与资源报告，不重写输入语义。

扩展时保持以下不变：

1. 音频采样率保持 48.000 kHz，I2S 格式不随手改动。
2. 输入先转换成统一语义，再进入 `input_map`。
3. 新功能先做独立 demo，再合入 v1.0 主线。
4. 每一步都保留可回退的板载 / 外接按键通路。
