# V1.0 范围与输入语义

> 状态：已确认
> 日期：2026-09-23
> 目的：冻结“可演示成品”的最小范围，并给后续触摸、TFT、效果器等增量功能提供稳定接口。

## 1. 这份文档回答什么

当前方案层已经基本闭环，但还不能称为“合格成品”。本文件把 v1.0 要交付的
功能、输入语义和扩展边界固定下来，后续开发按此执行，不再反复重排硬件模块。

## 2. V1.0 范围

### 2.1 必须交付

| 项目 | v1.0 目标 |
|---|---|
| 音频合成 | FPGA HDL 逐样本、逐声部实时生成，无预录 PCM |
| 复音 | 基础 4 复音，至少可演奏一个三和弦并保留一个声部 |
| 合成参数 | 独立相位累加器、频率控制、ADSR 包络、逐样本混音 |
| 音色 | Warm Sine / Bright Square，可实时切换 |
| 演奏输入 | 选音、触发、拨弦、力度感应 |
| 独立维度 | 至少 2 维；v1.0 采用 Pitch Bend、动态力度、扫弦间隔三线准备 |
| 摇杆 | 左右 Pitch Bend；前后扫弦间隔 / 琶音速度，只在和弦触发时锁存 |
| 超声波 | 手距映射到力度与慢速动态，靠近更强、远离更弱 |
| 效果器 | 至少合唱可开关，不引入爆音 |
| 输出 | I2S 到板载 MAX98357A，48.000 kHz |
| 显示 | 开发期使用旧 1.3 寸 OLED；TFT 作为后续替换 |
| 验证 | 测试模式、独立谱峰、RTL 纯硬件路径可讲解 |
| 延迟 | 控制信号到音频输出实测并文档化，目标 ≤10 ms |

### 2.2 V1.0 暂不做

- 不先做 PCB 母板，继续面包板 / 杜邦线验证。
- 不把 2.4 寸 TFT、触摸圆环、WS2812 灯环作为 v1.0 阻塞项。
- 不先做延迟、混响、蓝牙和手机 App。
- 不为了交互功能拖延测试模式、4 复音和 ≤10 ms 延迟验证。

## 4. 冻结的输入语义

后续无论输入来自按键、摇杆、超声波还是触摸，都先转换成下列语义，再交给
`input_map` 和合成引擎。不要把这些逻辑直接写死到某个传感器模块里。

| 语义字段 | 含义 | v1.0 来源 |
|---|---|---|
| `note_select` | 选择音名 / 和弦根音 | 按键、后续触摸 |
| `trigger` | 开始新音符或和弦 | 按键、后续触摸 |
| `pluck` | 拨弦型包络事件 | 短按 / 快速释放识别 |
| `velocity` | 单次触发力度 | note-on 时锁存超声波手距 |
| `expression` | 持续按住时的慢速动态 | 超声波平滑值 |
| `pitch_bend` | 实时音高偏移 | 摇杆左右，建议 ±2 semitone |
| `strum_interval` | 和弦内音符错开时间 | 摇杆前后，和弦触发时锁存 |
| `timbre` | 音色选择 | S1 / TIMBRE 键 |
| `fx_bypass` | 效果旁路开关 | S2 / FX 键 |

### 4.1 摇杆左右：Pitch Bend

- 中心为 0，松开自动回中。
- 建议死区覆盖机械抖动，有效范围约 ±2 半音。
- 实时改变相位增量或音高比例，不通过超声波参与快速音高控制。

### 4.2 摇杆前后：扫弦间隔 / 琶音

- 只在和弦触发时读取并锁存，避免按住和弦时连续变化造成 Bug。
- 向后拉：快速扫弦，接近同时触发。
- 中心：小幅扫弦或整齐和弦。
- 向前推：慢速扫弦 / 琶音。
- 建议范围：`0 ms` 同时触发，`15–30 ms` 可辨扫弦，`60–150 ms` 琶音。

### 4.3 超声波：力度 / 动态

- 手在传感器正前方 `10–50 cm` 范围内前后移动。
- 靠近：力度大、动态强；远离：力度小、动态弱。
- note-on 时锁存为 `velocity`。
- 持续按住时可输出平滑后的 `expression`，更新率按传感器约 10–20 Hz 设计。
- 必须加入中值滤波、死区和约 100–200 ms 平滑，禁止直接驱动快速滑音。

## 5. 后续增量功能的边界

这些功能后续可以加，不应推翻音频核心：

- 自研铜箔触摸圆环：只新增输入源，仍输出 `note_select / trigger / pluck`。
- 2.4 寸 TFT：只读取状态，不反向修改音频参数。
- 延迟 / 混响：接入现有效果器链路，先保证合唱旁路稳定。
- WS2812 / LED 曲目指引：只消费演奏和测试状态。
- 更高复音：依赖 `VOICES` 参数与资源报告，不重写输入语义。

扩展时保持以下不变：

1. 音频采样率保持 48.000 kHz，I2S 格式不随手改动。
2. 输入先转换成统一语义，再进入 `input_map`。
3. 新功能先做独立 demo，再合入 v1.0 主线。
4. 每一步都保留可回退的板载 / 外接按键通路。
