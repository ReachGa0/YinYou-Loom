## 1. 一句话任务

为作品设计一块**电容触摸前端模块**：**24 个触摸电极**（初步按"两圈、每圈 12 扇区"），
用 **2 片 MPR121**（12 通道/片）做检测，通过 **I2C + IRQ** 接到 Tang Nano 20K；
产出**原理图 + PCB**，并配套**文本化的网络表**（可以被我完全读懂、可版本管理）。

**本轮范围**：硬件设计（原理图、PCB、连接器、网络表）。
**不在本轮范围**：Verilog 驱动（`mpr121_ctrl.v` 等）、FPGA 工程、位流。

## 2. 开工前必须先问清用户（4 条，一次问完）

| # | 问题 | 为什么要问 | 备选 |
|---|---|---|---|
| 1 | **用 MPR121 模块（成品 breakout）还是裸芯片（QFN-20）？** | 模块焊盘好焊、可换；裸芯片省面积但要回流焊 | 建议：**先按模块设计**（可插拔，方便返工）；若做裸芯片需确认封装与焊接条件 |
| 2 | **24 个电极的物理形态与尺寸** | 决定 PCB 外形、电极面积、走线长度 | 建议：**两圈圆环**，内圈 12 扇区 + 外圈 12 扇区；电极面积 ≥ 8×8 mm，间距 ≥ 1 mm；中心留 Ø40 mm 以上给摇杆/屏幕 |
| 3 | **与核心板怎么连** | 决定连接器选型 | 2×20 排针/排母（对应 Tang Nano 20K 两侧排针）、杜邦线、或 FPC |
| 4 | **是否预留"自研 RC 测时"的备用焊盘** | 两条路线都试过是加分项 | 建议**留**：每个扇区旁边留一个 0603 电阻位 + 一个测试点，便于以后做 RC 对比实验 |

## 3. 电气设计要点（给画图的人，也给我自己审图）

### 3.1 MPR121 典型应用电路（每片）

| 项 | 取值/做法 | 说明 |
|---|---|---|
| 电源 | `+3V3` | MPR121 支持 1.71–3.6V；与 FPGA 同域，无需电平转换 |
| 去耦 | **0.1 µF + 1 µF** 就近电源脚 | 触摸芯片对电源噪声敏感，不能省 |
| I2C 上拉 | **SDA/SCL 各 4.7 kΩ 到 +3V3** | 与 ADS1115 共用总线时**整条总线只保留一组上拉**（不要每片都加） |
| ADDR | 片 1 接 `GND`、片 2 接 `+3V3` | 地址分别为 **0x5A / 0x5B**；与 ADS1115（0x48/0x49）不冲突 |
| IRQ | 每片一根引出到 FPGA | **优先用 IRQ**（触摸由芯片内部检测，延迟低）；轮询会拉长响应时间 |
| 电极连接 | 每片 12 路 → 12 个扇区 | 走线尽量短、等长、避免与 I2C/时钟线平行走线 |
| 滤波电容 | 每个电极到 GND 可留 1–10 nF 焊盘（不装） | 便于调试电磁干扰，先留位置 |

### 3.2 与 FPGA 的连接（引脚来自 `docs/15` §7 v2 提案，**待用户确认**）

| 信号 | FPGA 引脚 | 网络名 | 备注 |
|---|---:|---|---|
| I2C 时钟 | 77 | `I2C_SCL` | 与 2 片 ADS1115 **共用**同一条总线 |
| I2C 数据 | 85 | `I2C_SDA` | 同上 |
| MPR121 #1 中断 | 41 | `TOUCH_IRQ1` | v2 里由原 `MUX_S0` 改用途 |
| MPR121 #2 中断 | 42 | `TOUCH_IRQ2` | v2 里由原 `MUX_S1` 改用途 |
| 电源/地 | — | `+3V3` / `GND` | 与 FPGA 共地 |

> ⚠️ 若用户不同意 v2 引脚提案，必须先定引脚再画图——**不能先画图后改引脚**。

### 3.3 抗干扰与可靠性（可选但推荐）

- 电极所在层下方**大面积铺地**，电极周围留**护环（guard ring）**并接 GND；
- 模块与核心板之间的 I2C 线尽量短，超过 20 cm 建议双绞 + 就近上拉；
- 暴露在外的电极附近可留 **TVS 二极管阵列**位（不装），防静电；
- 24 电极的 12 路公共端顺序不要跨区交错，便于查线。

## 4. 交付物与格式约定（重要）

因为协作方要"能完全读懂"，约定如下：

| 交付物 | 格式 | 要求 |
|---|---|---|
| **网络表 / 连接表** | **Markdown 表格**（写进 `docs/15` 或本文档附录） | 逐条列出"器件位号 → 脚号 → 网络名"，与原理图一一对应 |
| 原理图 | EasyEDA 等工具绘制；**导出 SVG 或 PNG** 供审阅 | 若需协作方精修，优先给 **SVG（纯文本）** |
| PCB | 工具原生文件（`.eprj2` 等） | 协作方读不了原生文件，**关键尺寸/层叠/连接器位置必须同时写在文本里** |
| 打样前检查清单 | Markdown 清单 | 封装、丝印、1 脚方向、极性、连接器间距逐项核对 |

**注意**：`docs/15` 规定"芯片封装脚号 / 核心板排针脚号 / 成品模块排针脚号"是三个独立层次，
**禁止互相套用**；每件模块到货后必须实测并填写 `docs/15` §1.1 的记录表。

## 5. 协作规则（必须遵守）

1. **先读** `AGENTS.md` 与 `HANDOFF.md`，按 `AGENTS.md` 第六节**复述**当前阶段、
   已确认决策、下一步、禁止事项，**等用户确认后**再动手；
2. **决策分级**：真阻塞的（引脚、封装、连接器）立即问；可延后的（丝印字体、配色）不要现在问；
3. **不擅自修改 RTL / 工程 / 其他文档**；本轮只碰本任务相关的文档与图纸；
4. 工作区可能很脏（有未提交改动），**禁止 `git reset` / `git checkout --` / `git clean`**；
5. 每解决一个非平凡问题（例如"触摸电极布线干扰"），按 `AGENTS.md` 原则 9
   **就地追加**一条到 `docs/19_FPGA工程实践与踩坑记录.md`；
6. 合规边界（`docs/19` 案例 15）：**最终作品不含可编程器件参与功能**；
   MPR121 是固定功能触摸控制器 ✓ 合规；不要在这块 PCB 上放任何 MCU。
