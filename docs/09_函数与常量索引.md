## 一、Python 公共模块

文件：`tools/loom_common.py`

### 常量

| 名称 | 值 | 说明 |
|---|---|---|
| `FS` | `48000` | 音频采样率 (Hz) |
| `PHASE_BITS` | `32` | 相位累加器位宽 |
| `TABLE_BITS` | `12` | 波表地址位宽 |
| `TABLE_SIZE` | `4096` | 波表点数（`1 << TABLE_BITS`） |
| `AMP` | `32767` | 16bit 有符号峰值 |
| `PHASE_MOD` | `4294967296` | 相位模数（`1 << PHASE_BITS`） |

### 函数

| 函数 | 签名 | 说明 |
|---|---|---|
| `freq_to_inc` | `freq_to_inc(freq: float, fs: int = FS) -> int` | 频率 (Hz) → 调音字 |
| `inc_to_freq` | `inc_to_freq(inc: int, fs: int = FS) -> float` | 调音字 → 实际频率 (Hz) |
| `cents_error` | `cents_error(f_actual: float, f_target: float) -> float` | 音分误差；正 = 偏高 |
| `to_hex16` | `to_hex16(value: int) -> str` | 16bit 补码 → 4 位大写 hex |

### 调用示例

```python
from loom_common import FS, freq_to_inc, inc_to_freq, cents_error

inc = freq_to_inc(440)
fa = inc_to_freq(inc)
err = cents_error(f_actual=fa, f_target=440.0)
```

> 参数顺序提示：`cents_error` 的第一个参数是**实际频率**，第二个是**目标频率**。
> 用关键字调用可以彻底避免写反。

## 三之二、RTL 模块

### `rtl/common/frac_div.v`

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `STEP` | 8 | 每个时钟累加值 |
| `DEN` | 125 | 累加模数 |

- 端口：`clk` / `rst_n` / `tick`。
- 平均输出频率：`f_clk × STEP / DEN`。
- 当前配置：`72MHz × 8 / 125 = 4.608MHz`。
- `tick` 为单周期脉冲，余数保留到下一周期，因此长期平均频率精确。

### `rtl/synth/wavetable_rom.v`

| 参数 | 默认值 | 说明 |
|---|---|---|
| `ADDR_BITS` | 12 | 地址位宽（4096 点） |
| `DATA_W` | 16 | 样本位宽 |
| `INIT_FILE` | `"data/wavetables/sine_4096x16.hex"` | 波表文件（可换成 saw/triangle/square） |

- 端口：`clk` / `addr` / `data`（`signed`）。
- **同步读**：`data <= mem[addr]`，数据比地址晚 1 个时钟，便于推断 BSRAM。
- 注意：`$readmemh` 的相对路径相对于**运行 `vvp` 时的当前工作目录**，不是源文件所在目录。

### `rtl/synth/wavetable_bank.v`

| 参数 | 默认值 | 说明 |
|---|---|---|
| `ADDR_BITS` | 12 | 地址位宽 |
| `DATA_W` | 16 | 样本位宽 |
| `INIT_FILE0` | 正弦波表 | 主音色 |
| `INIT_FILE1` | 方波波表 | 第二音色 |

- 两张 ROM 由所有声部共享，存储量不随 `VOICES` 增长。
- `table_sel=0` 选择正弦表，`table_sel=1` 选择方波表。

### `rtl/synth/wavetable_arbiter.v`

- 在 `sample_en` 后依次扫描所有声部地址，从共享 bank 读取样本。
- 输出 `wave_sample_flat`、`wave_valid` 和 `scan_done`。
- 72MHz 下一个采样周期有 1500 个时钟，4/8/16/32 声部分时读取均有余量。

### `rtl/synth/voice_osc.v`

| 参数 | 默认值 | 说明 |
|---|---|---|
| `PHASE_BITS` | 32 | 相位累加器位宽 |
| `ADDR_BITS` | 12 | 查表地址位宽 |
| `SAMPLE_W` | 16 | 输出样本位宽 |

- 端口：`clk` / `rst_n` / `sample_en` / `inc` / `run` / `addr` / `wave_sample` / `wave_valid` / `sample` / `sample_valid`。
- `run = 0` 时相位保持，不清零。
- `addr` 由相位高位产生，样本由共享仲裁器按 voice 编号返回。

### `rtl/synth/voice_adsr.v`

| 参数 | 默认值 | 说明 |
|---|---|---|
| `LEVEL_W` | 16 | 包络电平位宽（0~65535） |

- 端口：`clk` / `rst_n` / `sample_en` / `gate` / `a_step` / `d_step` / `sustain_level` / `r_step` / `level` / `busy`。
- 五状态机：`IDLE → ATTACK → DECAY → SUSTAIN → RELEASE`。
- `step` 参数定义的是**每个采样周期的步进量**，换算公式：`step = 65535 / (时间秒 × 48000)`。
- 约束：所有 step 必须 ≥ 1，否则对应阶段永远走不完。
- 坑：`sustain_level + d_step` 必须加宽位宽再比较，否则 16 位加法溢出导致状态机卡死。

### `rtl/synth/voice.v`

- 声部层：`voice_osc` + `voice_adsr` + 定点乘法 + 每音高增益。
- 端口：`clk` / `rst_n` / `sample_en` / `inc` / `gate` / 包络参数 /
  `gain_q15` / `wave_sample` / `wave_valid` / `sample` / `sample_valid` / `busy`。
- `run = gate | busy`：**释放段振荡器必须继续跑**，否则输出被冻成直流值。
- 包络调制：`sample = (osc_sample × {1'b0, level})[31:16]`，即乘以 `level/65536`。
- `gain_q15` 使用 1/32 网格上的固定系数，通过移位和加减实现；输出再由
  `wave_valid` 打一级流水，避免 72 MHz 下出现 setup 违例。
- 坑：乘法前必须把两个操作数都变成**有符号**（`env_level` 要零扩展一位），否则 Verilog 按无符号运算，负半周会错乱。

### `rtl/synth/mixer.v`

- 多声部样本求和，并按 `gate_flat` 统计同时按下的声部数做归一化：
  `1/1`、`1/2`、`21/64≈1/3`、`1/4`，随后按 16bit 有符号范围饱和限幅。
- 使用两级流水将求和与归一化/限幅分开；`mix_valid` 对齐最终 `mix_sample`，
  `synth_top` 对外输出它作为新的 `scan_done`。

### `rtl/synth/synth_top.v`

- 参数 `VOICES` 控制声部数，默认 4。
- 内部例化 N 个 `voice`、1 个共享 `wavetable_arbiter` 和 1 个 `mixer`。
- 临时综合验证：4 声部和 8 声部的 BSRAM 都固定为 8 块。

### `rtl/synth/voice_alloc.v`

- `note_on` 优先分配空闲声部；无空闲声部时按轮转指针抢占。
- `note_off` 根据 `note_id` 释放对应声部。
- `voice_busy` 来自 ADSR，Release 尾音未结束前不会被复用。

### `rtl/synth/synth_engine.v`

- 把 `note_on / note_off` 事件转换为各声部的 gate 和 inc。
- 内置简化 A 加权增益表：C4=`1.0`、E4=`25/32`、G4=`11/16`、
  A4=`5/8`、B4=`9/16`；仅用于把当前窄音域内的听感响度拉近。
- 内部连接 `voice_alloc`、`synth_top`、共享波表和 mixer。
- 为 P4/P5 的按键和触摸事件提供统一音符入口。

### `rtl/input/key_scan.v`

- 多路低有效按键同步、消抖和按下/释放脉冲输出。
- 默认参数：`KEYS=4`，`DEBOUNCE_CYCLES=720000`；在 72 MHz 时钟域中约为
  `10 ms`。其他时钟域必须按 `clk` 频率覆盖该参数。

### `rtl/input/input_map.v`

- 把 P5A 四路按键事件映射为 C4/E4/G4/B4 的 `note_on/note_off`。
- v1.0 目标接口：按键、摇杆、超声波先统一为 `note_select / trigger / pluck /
  velocity / expression / pitch_bend / strum_interval`，再接 `synth_engine`。
- 摇杆左右映射 Pitch Bend；前后只在和弦触发时锁存扫弦间隔；超声波手距
  note-on 锁存力度、持续时输出慢速动态。详细定义见 `docs/16_V1范围与输入语义.md`。
- 输出统一接入 `synth_engine`，后续触摸圆环可复用同一音符事件接口。
- 音高与增益补偿已恢复正式映射，P5A 调试用临时 A4/C4 参数已移除。

### `rtl/input/rotary_decode.v`

- EC11 兼容编码器的 A/B 正交解码，输出旋转方向脉冲。
- 可选按压输入复用 `key_scan` 消抖；仅适用于确实引出 `SW` 或 `SW1/SW2` 的编码器。
- 当前实物模块为 5 脚 `A/C/B/VCC/GND`，其中 `C` 是公共端并接 `GND`，不能当作 `SW`。

### `rtl/p4_demo_top.v`

- 四声部上板演示顶层，上电后自动触发 C4/E4/G4/B4。
- 使用共享波表、`voice_alloc`、`synth_engine`、I2S 输出。
- 对应 Gowin 工程：`fpga/p4_demo/p4_demo.gprj`。
- 输出位流：`fpga/p4_demo/impl/pnr/p4_demo.fs`。

### `rtl/p5a_demo_top.v`

- 四路外接低有效按键驱动 `key_scan`、`input_map` 和 `synth_engine`。
- 按键映射为 C4/E4/G4/B4，可同时形成四声部和弦。
- 当前调试层 sustain 为 `32768`，与 P3 单音幅度一致；四键齐按时由 mixer
  饱和限幅保护，正式多声部版本如需更低失真可再增减益或做动态归一化。
- 对应 Gowin 工程：`fpga/p5a_demo/p5a_demo.gprj`。
- 输出位流：`fpga/p5a_demo/impl/pnr/p5a_demo.fs`。

### `rtl/synth/chorus.v`

- 单抽头调制延迟合唱，第一版固定为约 10.7~16.0 ms 延迟、约 0.37 Hz 三角 LFO、
  50% dry/wet。
- 旁路时仍保留与效果路径一致的两级流水延迟，顶层切换不会引入脉冲爆音。
- 已在独立 `timbre_fx_demo` 中与 S2 联调，实机开关正常。
- VIBRATO / TREMOLO 已从当前模块移除，只保留 DRY / CHORUS 内部能力。

### `rtl/synth/fx_engine.v`

- P6 统一四档：`DRY / CHORUS / DELAY / REVERB`。
- CHORUS / DELAY / REVERB 共用一块 16384×16 BSRAM，任一时刻只运行一种湿效果。
- 模式切换先输出干声并清空共享区，再用约 10 ms 渐变进入新效果，避免旧尾音串入。
- 共享 RAM 固定为单读口、单写口、同步读；状态机显式等待一拍读延迟。
- REVERB 每路线路使用 1/4 干声注入、约 0.625 反馈，最终输出为半干半湿，
  保证满幅共振输入下反馈环不削波。

### `rtl/synth/delay_effect.v`

- 12000 采样、16 位单抽头反馈延迟，约 250 ms。
- 反馈系数 0.5，使用移位实现，不增加持续 DSP 乘法需求。

### `rtl/synth/reverb_effect.v`

- 四路约 20.8–29.7 ms 的短反馈延迟。
- 四路湿声取平均，反馈约 0.625，形成多抽头衰减尾音。

### `rtl/timbre_fx_demo_top.v`

- 旧 OLED 音色 / 合唱联合演示顶层，不替代正式 `loom_top` 或 `p5a_demo_top`。
- 演奏键：PIN28-PIN31 = C4/E4/G4/B4。
- 音色切换：板载 S1=PIN88，仅在无按键且无 Release 尾音时切换 SINE/SQUARE。
- 效果切换：板载 S2=PIN87，切换 DRY/CHORUS。
- OLED：SCL=PIN71、SDA=PIN72，`PATTERN_MODE=2` 显示 `TIMBRE / FX / VOICE`。
- 音频输出：I2S DIN=PIN54、LRCK=PIN55、BCLK=PIN56、PA_EN=PIN51。
- 对应 Gowin 工程：`fpga/timbre_fx_demo/timbre_fx_demo.gprj`。
