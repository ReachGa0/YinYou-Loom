# 函数与常量索引

> 目的：一处查全项目所有公共常量、函数与 RTL 宏，避免参数顺序写错。
> 规则：新增或修改公共函数 / 宏后，同步更新本表。
> 相关文件：`tools/loom_common.py`、`rtl/common/loom_defs.vh`、`sim/run_sim.ps1`、`sim/run_all.ps1`。

---

## 一、Python 公共模块

文件：`tools/loom_common.py`

### 常量

| 名称 | 值 | 说明 |
|---|---|---|
| `FS` | `48000` | 音频采样率 (Hz) |
| `PHASE_BITS` | `32` | 相位累加器位宽 |
| `TABLE_BITS` | `12` | 波表地址位宽 |
| `TABLE_SIZE` | `4096` | 波表点数（`1 << TABLE_BITS`） |
| `AMP` | `32767` | 16bit 有符号峰值 |
| `PHASE_MOD` | `4294967296` | 相位模数（`1 << PHASE_BITS`） |

### 函数

| 函数 | 签名 | 说明 |
|---|---|---|
| `freq_to_inc` | `freq_to_inc(freq: float, fs: int = FS) -> int` | 频率 (Hz) → 调音字 |
| `inc_to_freq` | `inc_to_freq(inc: int, fs: int = FS) -> float` | 调音字 → 实际频率 (Hz) |
| `cents_error` | `cents_error(f_actual: float, f_target: float) -> float` | 音分误差；正 = 偏高 |
| `to_hex16` | `to_hex16(value: int) -> str` | 16bit 补码 → 4 位大写 hex |

### 调用示例

```python
from loom_common import FS, freq_to_inc, inc_to_freq, cents_error

inc = freq_to_inc(440)
fa = inc_to_freq(inc)
err = cents_error(f_actual=fa, f_target=440.0)
```

> 参数顺序提示：`cents_error` 的第一个参数是**实际频率**，第二个是**目标频率**。
> 用关键字调用可以彻底避免写反。

### `tools/spectrum.py`

| 函数 | 签名 | 说明 |

- 依赖：`numpy`

### `sim/tb_voice_osc.v`

- `tb_voice_osc`：440Hz 单声部仿真 testbench。
- 使用 `` `INC_440 ``、`` `WAVETABLE_SINE `` 和 `` `TABLE_SIZE `` 等公共宏。
- 输出：`sim/out/sine_440.txt`（4800 个样本）。

### `sim/run_sim.ps1`

- 一键仿真脚本，共 6 步：编译/运行单振荡器 testbench → 转 WAV → 频谱分析 → 编译/运行声部 testbench → ADSR 四段检查。
- 用法：
  ```powershell
  .\sim\run_sim.ps1 -Python "C:\...\python.exe"
  ```
- 参数：`-Python` 指定 Python 解释器；默认 `python`（PATH 中的 Python）。
- 产物：`sim/out/sine_440.txt`、`sim/out/sine_440.wav`、`sim/out/voice_dump.txt`（均在 `.gitignore` 中）。
- 注意：编译产物与运行产物必须同名（`sim/out/tb_voice_osc.vvp`），从干净目录跑也要通过。

### `tools/adsr_check.py`

| 函数 | 签名 | 说明 |
|---|---|---|
| `envelope_rms` | `envelope_rms(data, win=109)` | 按窗口求 RMS，得到平滑包络（正弦 RMS = 幅度/√2） |
| `find_plateau` | `find_plateau(env, tol=0.03)` | 找最长的近似恒定段（Sustain），判据是 `(max-min)/mean` |

- 命令行：`python tools/adsr_check.py sim/out/voice_dump.txt 30000`
- 作用：自动检查 Attack 上升 / Decay 下降 / Sustain 恒定 / Release 归零 / 电平符合理论值。
- 注意：窗口长度必须覆盖一个完整音周期（440Hz @48kHz ≈ 109 样本），否则峰值随相位抖动会导致平台检测失准。

### `sim/tb_voice.v`

- `tb_voice`：声部整体（振荡器 + ADSR）测试台。
- 采集 `sample_valid` 有效时的样本写入 `sim/out/voice_dump.txt`，采集循环带硬超时防止挂死。
- `SAMPLE_DIV` 用较小的值以加速仿真：**ADSR 形状只取决于样本数，与分频比无关，行为等价**。

### `sim/tb_frac_div.v`

- `tb_frac_div`：验证 72MHz 下 `frac_div(STEP=8, DEN=125)` 的平均输出为 4.608MHz。
- 检查 125 拍输出 8 个 tick、1250 拍输出 80 个 tick，并验证余数跨窗口保留。

### `sim/run_all.ps1`

- 全量回归脚本，当前覆盖音频链路、基础时钟模块、I2S、I2C、显示、共享波表和声部分配，共 **15 套测试**。
- 用法：
  ```powershell
  .\sim\run_all.ps1 -Python "<python路径>"
  ```
- 改动任何 RTL 后优先运行本脚本；`run_sim.ps1` 只负责音频链路的 WAV/FFT 验证。

## 三之二、RTL 模块

### `rtl/common/frac_div.v`

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `STEP` | 8 | 每个时钟累加值 |
| `DEN` | 125 | 累加模数 |

- 端口：`clk` / `rst_n` / `tick`。
- 平均输出频率：`f_clk × STEP / DEN`。
- 当前配置：`72MHz × 8 / 125 = 4.608MHz`。
- `tick` 为单周期脉冲，余数保留到下一周期，因此长期平均频率精确。

### `rtl/synth/wavetable_rom.v`

| 参数 | 默认值 | 说明 |
|---|---|---|
| `ADDR_BITS` | 12 | 地址位宽（4096 点） |
| `DATA_W` | 16 | 样本位宽 |
| `INIT_FILE` | `"data/wavetables/sine_4096x16.hex"` | 波表文件（可换成 saw/triangle/square） |

- 端口：`clk` / `addr` / `data`（`signed`）。
- **同步读**：`data <= mem[addr]`，数据比地址晚 1 个时钟，便于推断 BSRAM。
- 注意：`$readmemh` 的相对路径相对于**运行 `vvp` 时的当前工作目录**，不是源文件所在目录。

### `rtl/synth/wavetable_bank.v`

| 参数 | 默认值 | 说明 |
|---|---|---|
| `ADDR_BITS` | 12 | 地址位宽 |
| `DATA_W` | 16 | 样本位宽 |
| `INIT_FILE0` | 正弦波表 | 主音色 |
| `INIT_FILE1` | 方波波表 | 第二音色 |

- 两张 ROM 由所有声部共享，存储量不随 `VOICES` 增长。
- `table_sel=0` 选择正弦表，`table_sel=1` 选择方波表。

### `rtl/synth/wavetable_arbiter.v`

- 在 `sample_en` 后依次扫描所有声部地址，从共享 bank 读取样本。
- 输出 `wave_sample_flat`、`wave_valid` 和 `scan_done`。
- 72MHz 下一个采样周期有 1500 个时钟，4/8/16/32 声部分时读取均有余量。

### `rtl/synth/voice_osc.v`

| 参数 | 默认值 | 说明 |
|---|---|---|
| `PHASE_BITS` | 32 | 相位累加器位宽 |
| `ADDR_BITS` | 12 | 查表地址位宽 |
| `SAMPLE_W` | 16 | 输出样本位宽 |

- 端口：`clk` / `rst_n` / `sample_en` / `inc` / `run` / `addr` / `wave_sample` / `wave_valid` / `sample` / `sample_valid`。
- `run = 0` 时相位保持，不清零。
- `addr` 由相位高位产生，样本由共享仲裁器按 voice 编号返回。

### `rtl/synth/voice_adsr.v`

| 参数 | 默认值 | 说明 |
|---|---|---|
| `LEVEL_W` | 16 | 包络电平位宽（0~65535） |

- 端口：`clk` / `rst_n` / `sample_en` / `gate` / `a_step` / `d_step` / `sustain_level` / `r_step` / `level` / `busy`。
- 五状态机：`IDLE → ATTACK → DECAY → SUSTAIN → RELEASE`。
- `step` 参数定义的是**每个采样周期的步进量**，换算公式：`step = 65535 / (时间秒 × 48000)`。
- 约束：所有 step 必须 ≥ 1，否则对应阶段永远走不完。
- 坑：`sustain_level + d_step` 必须加宽位宽再比较，否则 16 位加法溢出导致状态机卡死。

### `rtl/synth/voice.v`

- 声部层：`voice_osc` + `voice_adsr` + 定点乘法。
- 端口：`clk` / `rst_n` / `sample_en` / `inc` / `gate` / 包络参数 / `wave_sample` / `wave_valid` / `sample` / `sample_valid` / `busy`。
- `run = gate | busy`：**释放段振荡器必须继续跑**，否则输出被冻成直流值。
- 包络调制：`sample = (osc_sample × {1'b0, level})[31:16]`，即乘以 `level/65536`。
- 坑：乘法前必须把两个操作数都变成**有符号**（`env_level` 要零扩展一位），否则 Verilog 按无符号运算，负半周会错乱。

### `rtl/synth/mixer.v`

- 多声部样本求和并按 16bit 有符号范围饱和限幅。
- `scan_done` 到达时锁存完整帧混音结果，避免读取半帧数据。

### `rtl/synth/synth_top.v`

- 参数 `VOICES` 控制声部数，默认 4。
- 内部例化 N 个 `voice`、1 个共享 `wavetable_arbiter` 和 1 个 `mixer`。
- 临时综合验证：4 声部和 8 声部的 BSRAM 都固定为 8 块。

### `rtl/synth/voice_alloc.v`

- `note_on` 优先分配空闲声部；无空闲声部时按轮转指针抢占。
- `note_off` 根据 `note_id` 释放对应声部。
- `voice_busy` 来自 ADSR，Release 尾音未结束前不会被复用。

### `rtl/synth/synth_engine.v`

- 把 `note_on / note_off` 事件转换为各声部的 gate 和 inc。
- 内部连接 `voice_alloc`、`synth_top`、共享波表和 mixer。
- 为 P4/P5 的按键和触摸事件提供统一音符入口。

## 四、修改指南

- 改采样率：只改 `loom_common.py` 的 `FS` 和 `loom_defs.vh` 的 `` `FS ``；同时检查波表文件名和调音字。
- 改波表点数：改 `TABLE_BITS` / `TABLE_SIZE`，重新运行 `gen_wavetable.py`，并更新 `loom_defs.vh` 里的波表路径和 testbench 的仿真参数。
- 新增公共函数：先放进 `loom_common.py`，在本表登记，再让其他脚本导入。
- 改完 RTL / 工具后，跑一次 `.\sim\run_all.ps1 -Python <python路径>` 做全量回归；确认 15 套测试均通过。
