# 函数与常量索引

> 目的：一处查全项目所有公共常量、函数与 RTL 宏，避免参数顺序写错。
> 规则：新增或修改公共函数 / 宏后，同步更新本表。
> 相关文件：`tools/loom_common.py`、`rtl/common/loom_defs.vh`、`sim/run_sim.ps1`。

---

## 一、Python 公共模块

文件：`tools/loom_common.py`

### 常量

| 名称 | 值 | 说明 |
|---|---|---|
| `FS` | `48000` | 音频采样率 (Hz) |
| `PHASE_BITS` | `32` | 相位累加器位宽 |
| `TABLE_BITS` | `12` | 波表地址位宽 |
| `TABLE_SIZE` | `4096` | 波表点数（`1 << TABLE_BITS`） |
| `AMP` | `32767` | 16bit 有符号峰值 |
| `PHASE_MOD` | `4294967296` | 相位模数（`1 << PHASE_BITS`） |

### 函数

| 函数 | 签名 | 说明 |
|---|---|---|
| `freq_to_inc` | `freq_to_inc(freq: float, fs: int = FS) -> int` | 频率 (Hz) → 调音字 |
| `inc_to_freq` | `inc_to_freq(inc: int, fs: int = FS) -> float` | 调音字 → 实际频率 (Hz) |
| `cents_error` | `cents_error(f_actual: float, f_target: float) -> float` | 音分误差；正 = 偏高 |
| `to_hex16` | `to_hex16(value: int) -> str` | 16bit 补码 → 4 位大写 hex |

### 调用示例

```python
from loom_common import FS, freq_to_inc, inc_to_freq, cents_error

inc = freq_to_inc(440)
fa = inc_to_freq(inc)
err = cents_error(f_actual=fa, f_target=440.0)
```

> 参数顺序提示：`cents_error` 的第一个参数是**实际频率**，第二个是**目标频率**。
> 用关键字调用可以彻底避免写反。

## 二、Verilog 公共头文件

文件：`rtl/common/loom_defs.vh`

| 宏 | 值 | 说明 |
|---|---|---|
| `` `FS `` | `48000` | 采样率 |
| `` `PHASE_BITS `` | `32` | 相位累加器位宽 |
| `` `TABLE_BITS `` | `12` | 波表地址位宽 |
| `` `TABLE_SIZE `` | `4096` | 波表点数 |
| `` `AMP `` | `32767` | 峰值 |
| `` `INC_440 `` | `32'd39370534` | 440Hz 调音字 |
| `` `WAVETABLE_SINE `` | `"data/wavetables/sine_4096x16.hex"` | 正弦波表路径 |
| `` `WAVETABLE_SAW `` | `"data/wavetables/saw_4096x16.hex"` | 锯齿波表路径 |
| `` `WAVETABLE_TRIANGLE `` | `"data/wavetables/triangle_4096x16.hex"` | 三角波表路径 |
| `` `WAVETABLE_SQUARE `` | `"data/wavetables/square_4096x16.hex"` | 方波表路径 |

用法：

```verilog
`include "loom_defs.vh"

reg [`PHASE_BITS-1:0] phase;
localparam INC = `INC_440;
initial $readmemh(`WAVETABLE_SINE, wavetable);
```

编译时加 include 路径：

```powershell
iverilog -I rtl/common -g2012 -o sim/out/tb_voice_osc.vvp sim/tb_voice_osc.v
```

## 三、各脚本函数

### `tools/gen_wavetable.py`

| 函数 | 签名 | 说明 |
|---|---|---|
| `make_sine` | `make_sine() -> list[int]` | 生成正弦波表 |
| `make_saw` | `make_saw() -> list[int]` | 生成锯齿波表 |
| `make_triangle` | `make_triangle() -> list[int]` | 生成三角波表 |
| `make_square` | `make_square() -> list[int]` | 生成方波表 |
| `write_hex` | `write_hex(filename, table) -> None` | 写 `$readmemh` 格式的 hex 文件 |

### `tools/tune_word.py`

- 从 `loom_common` 导入 `freq_to_inc` / `inc_to_freq` / `cents_error`。
- 命令行：
  - `python tools/tune_word.py 440` → 打印 440Hz 的调音字与实际频率误差。
  - `python tools/tune_word.py` → 打印 A0~C8 全音域最大误差。

### `tools/pcm2wav.py`

| 函数 | 签名 | 说明 |
|---|---|---|
| `read_samples` | `read_samples(path) -> list[int]` | 读每行一个十进制样本的文本 |
| `write_wav` | `write_wav(samples, path, fs=FS) -> None` | 写 16bit / 单声道 / 48kHz WAV |

### `tools/spectrum.py`

| 函数 | 签名 | 说明 |
|---|---|---|
| `read_wav` | `read_wav(path) -> (np.ndarray, int)` | 读 WAV，返回 (样本数组, 采样率) |
| `find_peak_freq` | `find_peak_freq(samples, fs, fft_size=4096, zero_pad=65536) -> float` | 加汉宁窗 + FFT，返回峰值频率 (Hz) |

- 依赖：`numpy`
- 命令行：
  - `python tools/spectrum.py` → 分析默认 WAV `sim/out/sine_440.wav`，目标 440Hz。
  - `python tools/spectrum.py sim/out/sine_440.wav 440` → 指定 WAV 与目标频率。
- 实测：440.186 Hz / 0.730 音分。

### `sim/tb_voice_osc.v`

- `tb_voice_osc`：440Hz 单声部仿真 testbench。
- 使用 `` `INC_440 ``、`` `WAVETABLE_SINE `` 和 `` `TABLE_SIZE `` 等公共宏。
- 输出：`sim/out/sine_440.txt`（4800 个样本）。

### `sim/run_sim.ps1`

- 一键仿真脚本：编译 testbench → 运行仿真 → 文本转 WAV → 频谱分析。
- 用法：
  ```powershell
  .\sim\run_sim.ps1 -Python "C:\...\python.exe"
  ```
- 参数：`-Python` 指定 Python 解释器；默认 `python`（PATH 中的 Python）。
- 产物：`sim/out/sine_440.txt`、`sim/out/sine_440.wav`（均在 `.gitignore` 中）。
- 注意：编译产物与运行产物必须同名（`sim/out/tb_voice_osc.vvp`），从干净目录跑也要通过。

## 四、修改指南

- 改采样率：只改 `loom_common.py` 的 `FS` 和 `loom_defs.vh` 的 `` `FS ``；同时检查波表文件名和调音字。
- 改波表点数：改 `TABLE_BITS` / `TABLE_SIZE`，重新运行 `gen_wavetable.py`，并更新 `loom_defs.vh` 里的波表路径和 testbench 的仿真参数。
- 新增公共函数：先放进 `loom_common.py`，在本表登记，再让其他脚本导入。
- 改完 RTL / 工具后，跑一次 `.\sim\run_sim.ps1 -Python <python路径>` 做端到端回归；确认峰值仍在 440Hz 附近。
