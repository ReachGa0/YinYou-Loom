## 1. 为什么现在做、范围卡在哪

面包板 + 杜邦线已经暴露过真实代价：这次 TFT 调试里 **DC 悬空**一个人废掉了三档速度实验
（见 docs/19 案例 16）。载板的价值就是**把"接触不良/插错孔"这类故障从系统里消掉**。

但铜箔会把引脚**钉死**，所以 v0 的范围严格按 `docs/14` §1 的既有方案收窄：

| 类别 | 处理 |
|---|---|
| 已实机验证的接口（I2S 音频 / TFT`71-76` / 四键 / 板载键 / 拨动开关 / 超声`26,80`） | **做专用排母**，带防插错丝印 |
| 未到货或未定型号的（ADS1115、MPR121、12 档调式旋钮、WS2812 去留、编码器去留） | **只引到"通用扩展排母"**，不固化专用接口 |

**默认决策（2026-10-12 用户确认"按默认来"）**：

1. 范围：只做已验证接口 + 一块通用扩展排母；
2. 电源：`+3V3` 从核心板取；另留 `+5V` 输入排针 + 跳线隔离（给背光/将来 WS2812）；
3. 形态：先做**最小可用小底板**（约 100×80 mm），面板版换板框即可；
4. 交付：脚本生成 + 自检，见第 4 节。

## 2. 第一步（已完成）：连接定义 + 自检 + 核对表

### 2.1 单一数据源

连接关系写在 [`tools/pcb/loom_carrier_v0.py`](../tools/pcb/loom_carrier_v0.py) 里，
它是**唯一**的事实来源：两条 1x20 母座的**物理顺序 → FPGA 引脚 → 网络名**、三个电源网络。

生成物：[`PCB/carrier_v0/连接表与电源核对.md`](../PCB/carrier_v0/连接表与电源核对.md)
（由脚本生成，不要手改；改连接请改脚本再重新生成）。

### 2.2 自检（不依赖 EDA，先把连接层错误挡在生成之前）

脚本自带 5 项断言，当前输出：

```text
排针脚总数   : 40（A 20 + B 20）
已命名信号脚 : 34
电源/地脚    : 6
结果         : 全部通过（无漏命名、无一脚两用、电源脚齐全）
```

其中"电源脚齐全"按 `docs/14` §2 的硬规矩检查：`+3V3` 必须**两处都接**
（`J_CORE_A-19`、`J_CORE_B-16`），`GND` 必须**三处都接**
（`J_CORE_A-20`、`J_CORE_B-2`、`J_CORE_B-15`），`+5V` 一处（`J_CORE_B-1`）。
重复出现的电源脚**不能只接其中一个**——这正是最容易被漏掉的接法错误。

## 3. 网络命名口径

- **已冻结接口用功能名**（`TFT_SCLK/MOSI/CS/DC/RES/BLK`、`AUDIO_*`、`KEY1_C4`…、`ULTRA_*`、`I2C_*`、`LED0-5`、`STATUS_WS2812`）；
- **用途未定的预留脚**用 `SPARE_<引脚号>`（`41/42/48/49/52/53/86`）。

> ⚠️ 与 `docs/15` §7.2 的差异：那里把 `71-76` 命名为 `OLED_*`（当时按 SPI OLED 写的），
> 到货实物是 ST7789 TFT，本项目统一改用 `TFT_*`；`docs/14` §4 的 `J_TFT` 控制器名也从
> `ILI9341` 改为 `ST7789VW`（8 脚顺序 `GND/+3V3/SCL/SDA/RES/DC/CS/BLK` 已于 2026-10-12 实测确认）。

## 4. 工具链与交付路径（可自检、可复现）

```text
tools/pcb/loom_carrier_v0.py   连接定义 + 自检 + 表格生成（唯一数据源）
        ↓
KiCad 10.0.6（本机已装，自带 Python + pcbnew）  生成原理图/PCB（脚本产出，不手点）
        ↓  kicad-cli sch erc / pcb drc
自动验证：电气规则 + 间距/短路 + "连接表 vs 生成结果"一致性
        ↓
你：导入立创 EDA 专业版（或直接用 KiCad）→ 目视核对 → 下单嘉立创
```

说明：AI 侧**不接管图形界面**（本环境原生 GUI 自动化不可用，而且点几千次鼠标画板是错工具）；
几何用脚本生成、用命令行 DRC 自检，改一次只需几秒重新生成，不会像手画那样改乱。

## 5. 需要人工确认的两件事（**必须做**，否则不要打样）

具体步骤见生成表的 §0，这里只列要点：

1. **母座方向**：两条母座的 **1 脚都在 Tang Nano 的 USB-C 一端**。
   `docs/14` §2 已警告：连接器符号可以旋转 180°，但**焊盘编号必须与实物一致**，两种表示不能混用。
2. **电源脚实测**：只给核心板供 USB-C 电，用万用表量核心板排针上的**每一个脚**，
   找出 `+3V3` / `+5V` / `GND` 的真实位置，与核对表第 2 列对照。
   **不依赖任何文档**——这是唯一能排掉"文档与实物不一致"这个风险的办法。

1. 加入专用排母（TFT / 超声 / 四键 / 两个开关），全部带防插错丝印；

## 7. 边界与禁止（继承 `docs/14` §7）

- 不按杜邦线颜色决定网络（网络只由脚本定义）；
- 不在模块尺寸/排针顺序未核实前固化其专用接口；
- 不把 5V 信号直接接进 FPGA IO；
- 不让 WS2812 的大电流回路穿过触摸模拟地；
- 不把核心板 5V、3V3 与外部电源无隔离地硬连接。

### 8.5 走线计划（未执行，按此顺序做）

> ⚠️ **按下表走线前先完成接口整改。** 表中第 2 条超声波和第 3 条六键/
> 四键分支已经过时；当前方案是 7 音名 + MODE 键，摇杆使用独立 RC 前级。
> 在嘉立创EDA中确认新接口前，本计划只能作为通道规划参考。

**规则**：信号线 **0.4mm**、电源线（`5V` / `5V_SEL`）**0.5mm**；过孔 0.6/0.3mm；**内层绝不走线**；
`GND`/`3V3` **一根线都不画**（交给内层平面，铺完之后它们的飞线会自己消失）。

**三条主干道 + 一处扇出区**（走线时留空，别放器件）：

| 通道 | 位置 | 用途 |
|---|---|---|
| 左边竖条 | x ≈ 3~18，y ≈ −19~−52 | 所有"跨侧"的线从这里翻：TFT 的 SCLK/MOSI/BLK、6 根按键、5V |
| 上横带 | y ≈ −18~−23（x 20~38 一带） | TFT 的 CS/DC/RES 从 U1 上去接 U3 |
| 下横带 | y ≈ −47~−51 | 按键、超声波的分支 |
| **U2→U11 扇出区** | x ≈ 69~107，y ≈ −38~−44（**≥6mm 高**） | 7 根 `SPARE` + 2 根 `I2C` 斜着扇进 U11 下排 |

**顺序**（先短后长）：

1. TFT 6 根：`TFT_CS`（U1-1 → U3-7 → H5）、`TFT_DC`（U1-2 → U3-6）、`TFT_RES`（U1-3 → U3-5）；
   `TFT_BLK`（U2-3）、`TFT_MOSI`（U2-17）、`TFT_SCLK`（U2-18 → U3-3 → H4）——后三根在 U2 那排，
   **先钻两条母座之间的空区，再从左端绕出来**（焊盘间隙只有 0.84mm，穿不过去）。
2. 超声波：`ULTRA_ECHO`（U2-4 → U4-3，走下横带）、`ULTRA_TRIG`（U1-11 → 穿中间空区 → 从右端 x≈71 出来 → 接 U4-2）。
3. 六个键：U1-8/9/10/12/13/14 → 中间空区 → 左端翻下去 → 下横带 → 各自按键 1 脚。
4. `SPARE_41/42/48/49/52/53/86`：U2 那排 → 斜着扇进 U11 下排（2/4/6/8/10/12/14 脚）。
5. `I2C_SCL/SDA`：U1-4/5 → 中间空区 → 右侧（顺路接 H6/H7）→ 从 U11 左边进 16/18 脚。
6. 电源：`5V`（U2-1 → 沿左边竖条往上 → U13-1）；`5V_SEL` 主干（U12-1 → 沿板上边缘 y≈−1.5 向右 →
   在 x≈76 拐下来 → 接 H2、C7 → 到 U11-19），C8 用短支线搭在主干上。

> 同一条通道里方向相反的两组线（例如 `SPARE` 往右、按键往左），**一组走顶层、一组走底层**，
> 各走各的，别在一层里硬挤。

### 8.6 六条硬规矩（都是踩过坑换来的）

1. **坐标语义**：本节的坐标是**器件中心**；若某批封装的"原点"在 1 脚，长条器件要自己换算
   （中心 = 1 脚 + 长度一半）。摆完量 U1 的 1 脚是否在 `(20, −25)` 就能验证。
2. **不要把器件放进安装孔中心 4mm 内**（U12 因此挪过一次）。
3. **U2 与 U11 之间必须留 ≥6mm 高的横向带**（U11 因此从 −39.27 上移到 −36.00）——
   低于 3mm 时 7 根 SPARE 物理上扇不出来。
4. **屏幕（2.4″ 模块）底下那块（x≈18~62、y > −16）不放器件**：屏幕靠母座架在 8.5mm 之上，
   放是放得下，但不好焊、不好换。
5. **左右竖条留空**（x ≈ 3~18 与 x ≈ 69~77）—— 这是信号上下翻的唯一通道。
6. **丝印三件套**：U11 的 1 脚、C8 的 `+`、U1/U2 的 `USB` 端；另外每个接口旁写明功能名。
