## 2. 作品形态 ✅

**名称：吟游 Loom —— 基于 Tang Nano 20K 的纯硬件实时多音色合成电子乐器引擎**

### 2.1 产品定位

一台**能真的弹、能听出表情、能现场被验证**的桌面合成器。不是「演示板」，是「乐器」。

### 2.2 三个必须做到的能力

**① 声部引擎（FPGA 纯 HDL）**

- 每个声部 = `独立相位累加器 + 频率控制字 + ADSR 包络` ← 严格对齐赛题 R1 振荡器判据
- 波表合成：多张单周期波表（正弦 / 三角 / 锯齿 / 方波）
- 波形与参数运行时可变，支持单音实时变调
- 主输出：逐样本混音 → 饱和限幅 → I2S
- **复音：基础 4，可参数化扩展至 8** ✅

**② 演奏交互（≥2 维，目标 3 维）**

| 维度 | 器件 | 映射 | 状态 |
|---|---|---|---|
| D1 音高选音 | 自研铜箔电容触摸（RC 测时） | 音名 / 选音 | 目标 |
| D2 力度 | 按键按下时长 / 触摸面积 / 外接摇杆档位（待定 ❓） | 音量 + 亮度 | 目标 |
| D3 连续表情 | 自研超声波测距 | 滑音 / 揉弦 / 表情量 | 目标 |
| 保底通路 | 板载按键（及外接按键 / 摇杆模块，数量按实物核实 ❓） | 触发 / 选音 | 保底 |

> 赛题原文是「任意**自研交互方案**」——指自研的**交互形态与逻辑**，不要求自研传感器。
> 本方案的自研前端（触摸 + 超声波）是差异化重点；板载 / 外接按键是稳定保底。

**③ 可验证性（很多队伍会死在这里）**

- `TEST_MODE` 开关：一键让 N 个振荡器输出互不成谐波关系的固定频率
- 频谱 App 对着喇叭拍 → 谱峰数量可数
- RTL 代码可现场翻阅 → 证明无预录 PCM
- **这个模式从第一天就写进架构，不能最后补**

### 2.3 拓展要求打哪几条 ❓

| 拓展项 | 目标 | 成本 | 建议 |
|---|---|---|---|
| E1 复音 ≥32 | 暂不承诺；先做到 4 → 8 | 中（取决于综合结果） | ❓ **综合后再评估** |
| E2 ≥3 维 + ≥2 音色 + 效果器 | 3 维 + 2 音色 ✅；效果器（混响 / 延迟 / 合唱）待定 | 中 | 3 维 / 2 音色 ✅；效果器 ❓ |
| E3 ≤5ms + 视听反馈 | 不承诺 5ms，走基础 ≤10ms；视觉 LED 起步 | 低 | 基础档优先 |
| E4 蓝牙 App | — | 极高 | ❌ **不打** |

## 4. 技术架构

### 4.1 时钟与采样率 ✅（PLL 配置待 EDA 验证）

```
板上 27MHz ──PLL──> 100.8MHz ──分频 2100──> 48kHz 采样使能
```

- 100.8 = 27 × 3.733…；100.8 MHz / 2100 = 48.0 kHz
- 48 kHz 是标准音频率，DAC 友好，也便于与电脑上录的音频对比
- **注**：100.8 MHz 是否落在 Gowin PLL 可用 VCO 范围内，要在 Gowin EDA 中实测确认

### 4.2 每个声部的资源预算（估算，需综合后校准）

| 资源 | 单声部 | 4 声部 | 8 声部 | 20K 总量 | 余量 |
|---|---|---|---|---|---|
| LUT | ~120 | ~480 | ~960 | 20736 | ✅ 充裕 |
| FF | ~55 | ~220 | ~440 | 15552 | ✅ 充裕 |
| BSRAM | 共享波表 | 共享 | 共享 | 容量待核实 ❓ | 需综合确认 |

> **关键结论：4/8 声部在 20K 上大概率放得下**，因为波表是**共享**的，只有相位 / 包络状态是每声部独立。
> 估算必须在 P4 用**真实综合报告**替换。
>
> ⚠️ 官方 PDF 只写「多个 18×18 DSP」，未给 DSP 数量；BSRAM 容量也需查 Gowin datasheet。

### 4.3 延迟预算（目标 ≤10ms，拓展 ≤5ms 暂不承诺）

| 环节 | 延迟 |
|---|---|
| 按键 / 触摸扫描 | 1ms（1kHz 扫描） |
| 声部分配 | 1 采样 = 0.021ms |
| 合成 + 混音 | 1~2 采样 ≈ 0.04ms |
| I2S 缓冲 | 1ms |
| DAC 重建 | ~1ms |
| **合计** | **≈3ms，全链路定长** |

> ❓ **测量边界待定**：从传感器变化算起？含不含 DAC 重建？P6 必须写清楚。

### 4.5 关键接口契约（「延后决策」成立的前提）

| 模块 | 接口契约 | 隔离了什么 |
|---|---|---|
| `voice_osc.v` | `clk / rst_n / sample_en / inc / run / sample` | 波形来源（纯波表 vs +加法） |
| `voice_adsr.v` | `gate / A / D / S / R / level` | ADSR 参数来源 |

## 8. 差异化卖点（报告叙事主线）

1. **国产 FPGA 上的纯硬件乐器**：在 20736 LUT4 的 Tang Nano 20K 上实现 4/8 复音，全靠共享波表 + 例化，而不是堆资源。
2. **纯硬件合规**：全链路可指着 RTL 逐行讲，无一行软件、无一段预录。
3. **自研交互前端**：电容触摸 + 超声波测距都是自研电路，不是成品传感器模块。
4. **可现场验证**：TEST_MODE 让「振荡器数量」变成**肉眼可数的谱峰**。
5. **可伸缩架构**：同一份 RTL 改一个 parameter 就能扩展复音数，体现工程完备性。
