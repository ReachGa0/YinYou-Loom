## 2. 作品形态 ❓ 待定

**候选名：Aurora — 基于 Tang Nano 20K 的纯硬件实时多音色合成器**

### 2.1 产品定位
一台**能真的弹、能听出表情、能现场被验证**的桌面合成器。不是"演示板"，是"乐器"。

### 2.2 三个必须做到的能力

**① 声部引擎（FPGA 纯 HDL）**
- 每个声部 = `独立相位累加器 + 频率控制字 + ADSR 包络` ← 严格对齐赛题"振荡器统计规则"
- 波表合成：多张单周期波表（正弦 / 三角 / 锯齿 / 方波 / 复合波）
- 波形与参数全部**运行时可变**，支持单音实时变调
- 主输出：24bit 累加 → 饱和限幅 → I2S

**② 演奏交互（≥2 维，目标 3 维）**
| 维度 | 器件 | 映射 | 采购风险 |
|---|---|---|---|
| D1 触发 + 选音 | 板载 6 按键（复用为 6~12 音） | 音名 / 触发 | 零 |
| D2 力度 | 按键按下时长 或 摇杆档位 | 音量 + 亮度 | 零 |
| D3 连续表情 | **光敏电阻 + 分压 → 板载 ADC 脚**，或外置 I2C ADC 读线性霍尔/FSR | 滑音 / 揉弦 / 滤波扫频 | 低 |
| D4（加分） | 红外对管做"无接触手势" | 拨弦触发 / 颤音 | 低 |

> 赛题原文是「任意**自研交互方案**」——指自研的**交互形态与逻辑**，不要求自研传感器。
> 但「无接触手势」是赛题点名的形态，**红外对管很便宜，值得加**。

**③ 可验证性（很多队伍会死在这里）**
- `TEST_MODE` 开关：一键让 N 个振荡器输出互不相同的频率
- 频谱 App 对着喇叭拍 → 谱峰数量可数
- RTL 代码可现场翻阅 → 证明无预录 PCM
- **这个模式必须从第一天就写进架构，不能最后补**

### 2.3 拓展要求打哪几条 ❓

| 拓展项 | 目标 | 成本 | 建议 |
|---|---|---|---|
| 1. 复音 ≥32 | **32**（20K 放得下，靠例化） | 极低 | ✅ **打** |
| 2. ≥3 维表情 + ≥2 音色 + 效果器 | 3 维 + 4 音色 + 延迟/合唱 | 中 | ✅ **打** |
| 3. ≤5ms 确定性延迟 + 视听反馈 | 延迟达标；视觉降级为 OLED/LED | 低（视觉已降级） | ✅ **打** |
| 4. 蓝牙 App 联动 | — | 极高 | ❌ **不打** |

## 4. 技术架构

### 4.1 时钟与采样率（✅ 建议锁定，不可轻易变）

```
板上 27MHz ──PLL──> 100.8MHz ──分频 2100──> 48kHz 采样使能
```
- **为什么不选 96kHz**：赛题写明「过采样不叠加加分」，标 96k 只会让"振荡器总数"这个核心指标变难看。
- 48kHz 是标准音频率，DAC 友好，也便于和电脑上录的音频对比。
- 100.8 = 27 × 3.733…，Gowin PLL 可配；先按 100.8/2100 = 48.0kHz 整。

### 4.2 每个声部的资源预算（估算，需综合后校准）

| 资源 | 单声部 | 32 声部 | 20K 总量 | 余量 |
|---|---|---|---|---|
| LUT | ~120 | ~3840 | 20736 | ✅ 充裕 |
| FF | ~55 | ~1760 | 15552 | ✅ 充裕 |
| BSRAM | 0（共享表） | 共享 1 张表 = 8KB | 144KB | ✅ 充裕 |

> **关键结论：32 声部在 20K 上大概率放得下**，因为波表是**共享**的，只有相位/包络状态是每声部独立。
> 这个估算必须在 W5 用真实综合报告替换掉。

### 4.3 延迟预算（目标 ≤5ms，基础线 ≤10ms）

| 环节 | 延迟 |
|---|---|
| 按键扫描 | 1ms（1kHz 扫描） |
| 声部分配 | 1 采样 = 0.021ms |
| 合成 + 混音 | 1~2 采样 ≈ 0.04ms |
| I2S 缓冲 | 1ms |
| DAC 重建 | ~1ms |
| **合计** | **≈3ms，且全链路定长 → 确定性无抖动** |

### 4.4 模块划分（少而清晰，适配新手）

| 文件 | 职责 | 难度 |
|---|---|---|
| `voice_osc.v` | 单声部波表振荡器（相位累加 + 查表） | ★★ |
| `voice_adsr.v` | ADSR 包络发生器 | ★★ |
| `voice_top.v` | 例化 N 个声部 + 混音 + 饱和限幅 | ★★★ |
| `i2s_tx.v` | I2S 发送器（BCLK/LRCLK/SDATA） | ★★ |
| `clk_pll.v` | 27MHz → 100.8MHz（Gowin IP） | ★ |
| `input_scan.v` | 按键消抖 + 光敏/红外采样 | ★★ |
| `voice_alloc.v` | 按键 → 声部分配（简单轮转即可） | ★★ |
| `test_mode.v` | 多频点测试音生成 | ★ |

## 8. 差异化卖点（写报告时的叙事主线）

1. **资源效率**：在只有 6 万个 LUT**三分之一**的国产 FPGA 上做到 32 复音 —— 靠的是共享波表 + 例化，不是堆资源。
2. **纯硬件合规**：全链路可指着 RTL 逐行讲，无一行软件、无一段预录。
3. **可现场验证**：TEST_MODE 让"吞吐量"这个评分指标变成**肉眼可数**的谱峰。
4. **可伸缩架构**：同一份 RTL 改一个 parameter 就能跑在 138K 上 —— 体现工程完备性。
