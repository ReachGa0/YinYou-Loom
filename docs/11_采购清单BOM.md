# 采购清单 BOM

> 用途：一次性把整个项目要用的器件买齐，避免反复等快递。
> 价格为本文件编写时的参考区间，以实际下单为准。

## 当前采购结论（2026-09-23）

P5A 已完成，当前不需要继续购买产品形态器件。最近值得下单的只有：

| 优先级 | 物品 | 原因 |
|---|---|---|
| 1 | **HC-SR04P（3.3V 版）** | P5C 需要一个可直接接 FPGA 的 Echo；普通 HC-SR04 必须做电平保护 |
| 2 | **公对公杜邦线** | 面包板、现有模块和 FPGA 排针之间连接 |
| 3（P6 前） | **CY7C68013A 8 通道 24MHz 逻辑分析仪** | I2S 时序与端到端延迟实测，不急于在 P5C 前购买 |

暂时不要购买：额外 CD74HC4067、ADS1115、TFT、WS2812 灯环、5V 电源、
74AHCT125、电位器和旋钮帽。五个引脚的 EC11 编码器、两块 ADS1115、现有
摇杆以及现有 CD74HC4067 已够当前验证使用。铜箔、电阻包和面包板也等 v1.0
主线完成后，确认还有余力再做触摸预验证时购买。

### 模块本身是否需要外接电阻

| 模块/方案 | 是否需要外接电阻 | 说明 |
|---|---|---|
| HC-SR04P（3.3V 版） | 否 | 直接用 3.3V 供电，Echo 不再接 5V |
| 普通 HC-SR04（5V 版） | 是 | Echo **必须做电平保护**（分压或电平转换）。`1kΩ + 2kΩ` 在 5.0V 下标称 3.33V、5.25V 时约 3.5V，**不是安全余量**，不作为推荐方案 |
| EC11 编码器模块 | 通常否 | 模块或 FPGA 内部上拉即可；模块无上拉时再按实测补 |
| ADS1115 模块 | 通常否 | 成品模块一般自带 I2C 上拉和去耦 |
| CD74HC4067 模块 | 否 | 它只是模拟多路复用器，本身不是触摸芯片 |
| 自研铜箔电容触摸 | 很可能需要 | 铜箔是电极/电容，电阻用于构成 RC 充放电时间；具体阻值在 P5B 实验中确定 |
| 带触摸芯片的成品触摸模块 | 通常否 | 触摸检测和阻容网络都在模块上，但不再等同于当前“自研触摸前端” |

**概念澄清**：所谓“金属膜电阻”里的“膜”只是电阻制造工艺，不是用来制造电容。
触摸时真正变化的是铜箔电极对地的几 pF 电容；电阻的作用是把电容变化转换成
可测量的充放电时间。若使用 HC-SR04P、EC11、ADS1115、CD74HC4067 这些成品
模块，不应仅因为“用了模块”而额外串电阻；只有普通 5V 超声波模块和自研
电容触摸前端才需要按电路添加。

### 两个选型要点

**① 超声波优先买 `HC-SR04P`（带 P 的）**

| 型号 | 供电 | Echo 电平 | 接入 FPGA |
|---|---|---|---|
| `HC-SR04` | 必须 5V | 5V | ⚠️ **必须做电平保护**（分压或电平转换），否则烧引脚 |
| `HC-SR04P` | 3.3~5.5V | 3.3V 供电时输出 3.3V | ✅ 可直接接 |

买不到 P 版时，用普通版 + 电阻分压。**分压必须留余量**：5V 电源实际可能到 5.25V，
`1kΩ + 2kΩ` 会输出约 3.5V，已越过 FPGA 的 3.3V 电平，因此改用下列比例之一：

```
HC-SR04 Echo ──2kΩ──┬── 3.3kΩ ── GND
                     │
                     └──> FPGA 引脚（5.0V 时 ≈3.11V，5.25V 时 ≈3.27V）

或：1kΩ 串联 + 1.5kΩ 下拉（5.0V 时 ≈3.0V）
```

**上电前必须实测**：先只接分压电阻、不接 FPGA，用万用表量 Echo 高电平，
确认稳定 ≤3.3V 后再接入 `ULTRA_ECHO`（PIN80）。HC-SR04P 同样建议实测一次
Echo 高电平，因为个别批次模块的 Echo 驱动电平可能高于 3.3V。

> 说明：`HC-SR04P` 在 3.3V 供电下的测距范围、重复性与抗干扰表现**尚未实测**，
> 属于待验证假设。若实测发现抖动或丢回波偏多，再评估改用"5V 供电 + 电平保护"。

**② 板载只有 2 个按键**

KEY_S1 = PIN88、KEY_S2 = PIN87。它们保留为保底输入。主功能键使用第 7 项
外接 4 个轻触开关；v1.0 演奏由双轴摇杆、HC-SR04P 和外接按键共同完成，
两圈铜箔触摸只作为后续增量。
