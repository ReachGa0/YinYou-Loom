# REVERB 单条延迟线诊断工程

在 REVERB 档固定合成器输入音色为 SINE，且反馈为零。S1 对应的 TONE 界面选中项用于选择湿声抽头：SINE = 0、SQUARE = 1、SAW = 2、TRIANGLE = 3。其他 FX 档位保持原来行为。

按键后先松开音符，等声部释放，再按 S1 切换抽头；该工程的音色选择在声部空闲时生效。用 MODE 切到 ONE，每条都按住同一音键，分别记录有无撕裂声。湿声经过 1/4 注入、1/2 输出，声音可能比 DRY 小。

诊断代码仅供定位，不合入正式效果器。`sim/tb_reverb_tap_probe.v` 验证四路各自的脉冲延迟和互不混入。

2026-10-29：四路正负脉冲仿真通过，setup / hold 0/0；诊断位流已烧录 SRAM，User Code `0x0000CC11`。用户试听结果：四路都有撕裂声，主观严重程度 SAW < SQUARE < SINE < TRIANGLE。

另对独立效果器模块生成 Gowin 布局布线后模型，使用厂商存储器原语仿真；6000 个连续正弦样本、四路输出与逐样本延迟参考一致。此模型不含完整演示顶层，也不证明实际硬件及模拟音频链路无误。
