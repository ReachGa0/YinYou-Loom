# 李萨如显示独立验证工程

此工程复制 P6 顶层，使用相同接线。左侧显示音频相位轨迹：横坐标是 FX 输出采样，纵坐标是该信号延迟 16 个采样周期后的值；多音时显示的是复合信号的相位轨迹。右侧纵向排列 TONE、FX、MODE 菜单。

轨迹采用 112×112 有效点阵，每点显示为 2×2 像素，显示区域为 224×224；缓冲在刷新边界切换，采样写入另一块缓冲。静音显示中心点。显示端仅读取音频数据。

为减少 SPI 流量，两帧点阵按 14 条水平带比较，每条 224×16 像素，仅重画发生变化的带；旧点被清除也会触发重画。首次更新重画全部带。采样窗口不短于 20 ms，避免无变化时采样时间过短。密集变化时仍可能需要重画所有带，实际帧率与实机观感待测。

实机首版在按键有声音时仍只看到小点。显示坐标原先按 16 位满量程固定缩放，可能使普通音量的轨迹过小；现按帧峰值选择显示增益，并对放大结果限幅。增益目标连续三帧保持一致时，每次只调整一档，以减少频繁跳变；增益仅作用于显示。

```powershell
& 'C:\Gowin\Gowin_V1.9.11.03_Education_x64\IDE\bin\gw_sh.exe' fpga/lissajous_demo/build.tcl
```

```powershell
iverilog -g2012 -o tmp/tb_lissajous_capture.vvp sim/tb_lissajous_capture.v rtl/display/lissajous_capture.v
vvp tmp/tb_lissajous_capture.vvp
```
