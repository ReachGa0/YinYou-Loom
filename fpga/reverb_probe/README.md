# REVERB 无反馈诊断工程

基于当前李萨如演示工程建立的临时独立工程。仅将 REVERB 四路延迟线的反馈写入设为零，保留输入注入、延迟线读写、输出混合和其他 FX 模式。REVERB 的尾音因此会明显变短，此工程只用于定位持续噪声。

对比方法：切入 REVERB，等待安静后弹一个单音并松开，观察噪声是否在正常延迟后继续持续；再切回 DRY 确认。用户的观察是实机证据，不可仅凭诊断版结果认定根因。

运行 `gw_sh.exe fpga/reverb_probe/build.tcl` 构建，`sim/tb_reverb_probe.v` 验证首个延迟抽头、零反馈写入及延迟线读完后的静音。未经后续确认，不将这个临时改动合入正式效果器。

2026-10-29：诊断测试通过，原工程全量回归 47/47 通过；独立工程 setup/hold 均 0 违例。诊断位流烧录 SRAM，User Code `0x0000FCB9`。用户确认关闭反馈后按键时仍有噪声，松键后不再持续。进一步分量测试：干声正常，湿声仍有撕裂；原因尚待定位。
