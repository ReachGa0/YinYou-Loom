# REVERB 第 0 路板载样本比较诊断

本工程沿用单路湿声诊断版，仅在 REVERB + TONE 显示 SINE 时启用比较。将输入样本右移三位，存入独立的 997 样本参考延迟线，与第 0 条湿声输出逐样本比较；不向音频通路写入诊断数据。由于参考及被测路径均由同一 FPGA 实现，比较一致仍不代表输入、I2S 或模拟链路一定无问题。

板载 LED 低电平点亮：LED1（PIN16）亮表示累计一整条延迟线后已开始有效比较；LED0（PIN15）亮表示曾检测到不一致并锁存。退出 REVERB 或切换 TONE 会清空标志；重新进入并等待 LED1 亮可重新测量。先确认 TONE=SINE、FX=REVERB、MODE=ONE，等 LED1 亮且 LED0 灭，再按住单音并观察 LED0 与听感。

`sim/tb_reverb_sample_compare.v` 覆盖正常样本、不匹配锁存和停用时清除。工程通过 `build.tcl` 构建，仅供诊断。

2026-10-29：比较器单元仿真通过，既有全量回归 47/47，独立工程 setup/hold 0/0、BSRAM 34/46。诊断版烧录 SRAM，User Code `0x0000CE3A`。用户观察：按键前仅 LED1 亮；按键后 LED0 与 LED1 均持续亮起，说明比较器曾记录不一致。

后续用独立的效果器加比较器模块生成 Gowin 布局布线后模型，并用厂商存储器原语仿真：静音时比较器就绪且无错误，接续 5000 个正弦样本仍无不一致。此模型不包括完整顶层，尚不能排除实机比较器误报或完整系统中的问题。
