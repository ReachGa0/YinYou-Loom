## 这是什么

**吟游 Loom** 是一套完全运行在国产高云 GW2AR-LV18（Sipeed Tang Nano 20K）FPGA 硬件逻辑中的实时多音色合成电子乐器引擎。

它把音频合成的整条通路 —— 振荡器、包络、混音、输出 —— 全部实现在 HDL 硬件逻辑里，
**没有一行软件参与发声**。所有声音都由 FPGA 根据实时演奏指令**逐音、逐样本**生成，
不包含任何预录 PCM 音频、预置推流或整段录音触发。

交互侧采用"**自研交互语义 + 成品传感器模块 + 板载保底**"的结构：摇杆负责
Pitch Bend 与和弦扫弦间隔，超声波负责力度 / 动态；自研电容触摸作为后续升级项。
板载 2 个按键（KEY_S1=PIN88、KEY_S2=PIN87）始终保留为稳定备份。
三路输入最终映射为 **≥3 个独立可控演奏维度**。

系统内置**测试模式**，可同时输出多路固定频率信号，
使并发振荡器的数量在频谱仪上**直接可观测、可计数**。

## 硬件平台

| 项目 | 内容 |
|---|---|
| 开发板 | **Sipeed Tang Nano 20K**（自备板） |
| FPGA 芯片 | 高云 **GW2AR-LV18QN88C8/I7** |
| 逻辑资源 | 20736 LUT4 / 15552 FF / **48 × 18×18 DSP** |
| 时钟资源 | 2 × PLL ｜ 板载 27 MHz 晶振（PIN4）｜ MS5351（25MHz 晶振） |
| 存储资源 | **828K bit BSRAM（46 块）** ｜ **64M bit SDRAM** ｜ **64M bit QSPI Flash** |
| 音频输出 | **板载 MAX98357A I2S DAC+PA**（BCLK=PIN56 / LRCLK=PIN55 / DIN=PIN54 / PA_EN=PIN51）→ J4 小喇叭 |
| 板载外设 | 6 × LED（PIN15-20）｜ 1 × WS2812（PIN79）｜ 2 × 按键（PIN88/PIN87） |
| 工具链 | **Gowin EDA V1.9.11.03 Education**（支持本芯片，无需 license） |

**音频时钟方案**

```
板载 27 MHz 晶振 → rPLL(IDIV=3,FBDIV=8,ODIV=8) → 72.000 MHz
                     ├─ frac_div(8/125) ──> bit_tick 4.608 MHz（长期平均精确）
                     └─ i2s_tx ÷2 ────────> BCLK 2.304 MHz
                                              48 BCLK / 帧 → 48000.000 Hz
```

> **方案演进记录**：
> 1. 原定 100.8MHz 不可行——需分频比 224/15 或 448/15，超出 rPLL 的 FBDIV ≤ 64、IDIV ≤ 64 限制；
> 2. 69.12MHz 在数学上可达，但 `fPFD = 27 ÷ 25 = 1.08MHz`，低于 Gowin 的 3MHz 下限，布局布线必然报错；
> 3. **最终方案**：72MHz，`27 × 8 ÷ 3 = 72`，`fPFD = 9MHz`，VCO = 576MHz，
>    再用 `frac_div` 以 8/125 的比例产生平均 4.608MHz 位节拍，最终长期平均采样率为 **48000.000 Hz**。
>
> 关键公式（来自官方 UG286）：`f_CLKOUT = f_CLKIN × FBDIV / IDIV`，`f_VCO = f_CLKOUT × ODIV`。
> `fPFD = f_CLKIN / IDIV`，必须落在 3~500MHz；**ODIV 不参与输出分频**，只影响 VCO。
>
> ⚠️ Gowin IP Wizard 会自动替换手填的分频参数（它偏好简洁比值），最终参数以
> `fpga/loom/src/gowin_rpll/gowin_rpll.v` 里的 `defparam` 为准，勿再打开向导重新生成。
> 当前已完成综合、布局布线与位流生成；时序报告确认 PLL 输出为 72.000MHz，setup/hold 违例均为 0。

## 系统架构

系统分为三层，全部由 HDL 实现：

```
┌─────────────────────────────────────────────────────────────┐
│  交互层  Interaction                                        │
│  ───────────────────────────────────────────────────────    │
│  摇杆：Pitch Bend  ｜  扫弦间隔 / 琶音                       │
│  超声波：力度 / 动态  ｜  后续：自研铜箔触摸                  │
│  保底：板载按键  ｜  外接按键                                 │
│                         ↓                                   │
│         选音  ｜  触发 / 拨弦  ｜  力度  ｜  音高弯音         │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  合成层  Synthesis                                          │
│  ───────────────────────────────────────────────────────    │
│  每个声部 = 独立相位累加器 + 频率控制字 + ADSR 包络           │
│  波表合成架构  ｜  多声部并行例化（parameter VOICES）         │
│                         ↓                                   │
│              逐样本混音  →  饱和限幅  →  主增益              │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  输出层  Output                                             │
│  ───────────────────────────────────────────────────────    │
│  I2S 发送器（BCLK / LRCLK / SDATA）  →  外部 DAC            │
└─────────────────────────────────────────────────────────────┘
```

**设计要点**

- **每个声部都是完整的独立振荡器** —— 包含独立相位累加器、频率调控与包络控制。
- **复音数是一个可综合的参数** —— 通过声部并行例化获得，而非软件调度，因此可随器件规模伸缩。
- **波表为所有声部共享** —— 大幅降低存储开销，使复音数主要受逻辑资源而非存储资源约束。
- **整条通路为定长流水线** —— 延迟确定、可预测、可测量。
- **板载外设已核实** —— 核心板提供 2 个用户按键、6 个 LED 和 1 颗 WS2812；BSRAM/SDRAM 规格已写入 `docs/10_硬件引脚与资源.md`。
